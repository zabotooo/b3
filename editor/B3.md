# B3: building and testing the editor

This directory is the Scratch editor monorepo (`scratchfoundation/scratch-editor`,
branch `develop`), imported with `git subtree --squash`. Update with:
`git subtree pull --prefix=editor https://github.com/scratchfoundation/scratch-editor.git develop --squash`

All commands need Node 24.21.0:

    export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 24.21.0

## Install

    cd editor && PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci

`PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`: the `playwright-chromium` dependency downloads a
browser on install (and fails on Ubuntu 26.04, which Playwright 1.52 does not support).

Removed install-time steps (B3):
- root `prepare: husky install` — would install Scratch's git hooks into our repository;
- scratch-gui `prepare: node scripts/prepare.mjs` — downloaded the micro:bit hex from
  Scratch servers; `src/generated/microbit-hex-url.cjs` is a committed stub instead.

## Build (order matters, once after install or after changing these packages)

    npm run build --workspace @scratch/task-herder
    npm run build --workspace @scratch/scratch-storage
    npm run build --workspace @scratch/scratch-svg-renderer
    npm run build --workspace @scratch/scratch-render
    npm run build --workspace @scratch/scratch-vm      # also needed for scratch-gui's TypeScript types and Jest
    cd packages/scratch-gui && npm run build:dev        # -> packages/scratch-gui/build/index.html (served by hatd)

The scratch-gui webpack build bundles scratch-vm from `src`, but its Jest tests and
TypeScript types use `packages/scratch-vm/dist` — rebuild scratch-vm after VM changes
before running GUI tests that load the VM.

## Tests

    cd packages/scratch-vm && npx tap test/unit/b3_*.js          # B3 VM tests
    cd packages/scratch-gui && npx jest test/unit                  # GUI unit tests (baseline: 328 passed, 1 skipped)

GUI integration and Playwright suites need a browser and are not part of the B3 loop.
