# B3 hatd (Plan 1 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `hatd`, the Python daemon on the Raspberry Pi that owns the Build HAT and exposes the B3 HTTP/REST/WebSocket API (login, projects, sounds, hardware commands, telemetry, control lock).

**Architecture:** One asyncio process using aiohttp. Hardware is behind a `HatBackend` interface with a `SimBackend` (tests, development) and a `BuildHatBackend` (real hardware, wraps the blocking `buildhat` library with `asyncio.to_thread`). WebSocket clients send `{id, cmd, args}` commands, get replies, and receive pushed telemetry, device and control messages.

**Tech Stack:** Python ≥ 3.11 (Pi: 3.11.2 bookworm), aiohttp ≥ 3.8 (Pi apt: 3.8.4), `buildhat` 0.6.0 (Pi apt `python3-build-hat`), pytest ≥ 7.2, pytest-asyncio ≥ 0.20, `aplay`/`amixer` (alsa-utils).

**Spec:** `docs/superpowers/specs/2026-10-14-b3-design.md`

This is plan 1 of 3. Plan 2 = editor fork + B3 extension, Plan 3 = install script + release CI. Each is written after the previous one is done.

## Global Constraints

- License: AGPL-3.0 (whole repository).
- Product name "B3" (BuildBrickBlocks); never use "LEGO" or "SPIKE" in product names, UI or package names.
- Python code must run on Python 3.11 with aiohttp 3.8.4 (Pi apt versions) — no aiohttp ≥ 3.9-only APIs without fallback, no pip on the Pi.
- Ports are exactly `A`, `B`, `C`, `D`.
- Speeds are integers −100…100 (%); positive = clockwise.
- WebSocket API version string: `"1"`.
- Controller heartbeat: `ping` every 1 s; release + stop all after 3 s without ping (`control_timeout = 3.0`).
- Telemetry rate: 20 Hz (`telemetry_interval = 0.05`).
- Wrong PIN: error only, **no lockout**.
- Low voltage warning threshold: VIN < 7.0 V (shown by the editor; hatd only reports `vin`).
- Sounds are WAV only (the editor converts other formats before upload).
- Data dir layout: `<data_dir>/projects/`, `<data_dir>/sounds/`; config file `<data_dir>/config.toml`.
- No work on the Raspberry Pi 4 (<pi-ip>) or the Pi Zero 2 W (<zero-ip>) — copying files, installing packages, running tests — without the user's explicit consent for that step.

### Spec amendments made in this plan (also applied to the spec)

- `motor.set_relative` dropped from V1 — its only block (`flippermoremotor_motorSetDegreeCounted`) is in the out-of-V1 More Motors extension.
- Motor direction is the sign of `speed` (no separate `direction` arg); `rotations` are converted to degrees by the editor.
- Movement: `pair.*` takes per-wheel values and speeds; the editor converts steering. Pairs are synchronised with `asyncio.gather`, not `buildhat.MotorPair` (MotorPair opens its own `Motor` objects and fails with "Port already used" because hatd already owns the ports).
- `control` message is sent per client: `{type: "control", holder, you}`.

## Review Focus

1. **Controller's browser vanishes mid-run** (tab closed / Wi-Fi drop) — motors and sound must stop and control must be released (immediately on clean close, within `control_timeout` otherwise); another client can then claim. → Task 6 + Task 7 tests.
2. **Device swapped or unplugged on a port while a program runs** — commands fail with `no_device` / `wrong_device` naming the port; the telemetry loop must keep running and send a `device` message. → Task 8 + Task 9 tests.
3. **Malformed WebSocket input** (non-JSON, no hello, unknown cmd, port `"E"`, speed `500`, speed `true`, `NaN`) — an error reply, never a closed connection or crashed daemon. → Task 7 + Task 8 tests.
4. **Hostile project/sound uploads** (id with `../`, non-zip body, wrong md5, MP3 instead of WAV) — 400, nothing written outside the data dir. → Task 4 + Task 5 tests.
5. **`stop_all` while `motor.run_for` is waiting** — the pending reply must resolve promptly with `interrupted`, not hang. → Task 2 + Task 8 tests, and a hardware test in Task 11.

```python
class B3Error(Exception):
    """Error reported to clients as {code, message, port?}."""

    def __init__(self, code: str, message: str, port: str | None = None):
        super().__init__(message)
        self.code = code
        self.message = message
        self.port = port

    def to_dict(self) -> dict:
        d = {"code": self.code, "message": self.message}
        if self.port is not None:
            d["port"] = self.port
        return d
```

```python
"""Catalogue of Powered Up devices supported by the Build HAT."""

from dataclasses import dataclass
from enum import Enum

from .errors import B3Error

PORTS = ("A", "B", "C", "D")

# Colour names accepted by buildhat.Matrix (index 0-10)
MATRIX_COLORS = ("black", "pink", "lilac", "blue", "cyan", "turquoise",
                 "green", "yellow", "orange", "red", "white")


class Kind(str, Enum):
    MOTOR_ABS = "motor_abs"
    MOTOR_REL = "motor_rel"
    MOTOR_PASSIVE = "motor_passive"
    LIGHT = "light"
    MATRIX = "matrix"
    COLOR = "color"
    DISTANCE = "distance"
    FORCE = "force"
    COLOR_DISTANCE = "color_distance"
    WEDO_TILT = "wedo_tilt"
    WEDO_MOTION = "wedo_motion"


@dataclass(frozen=True)
class DeviceInfo:
    typeid: int
    name: str
    kind: Kind


_DEVICES = [
    DeviceInfo(1, "Simple Motor", Kind.MOTOR_PASSIVE),
    DeviceInfo(2, "Train Motor", Kind.MOTOR_PASSIVE),
    DeviceInfo(8, "Light", Kind.LIGHT),
    DeviceInfo(34, "WeDo 2.0 Tilt Sensor", Kind.WEDO_TILT),
    DeviceInfo(35, "WeDo 2.0 Motion Sensor", Kind.WEDO_MOTION),
    DeviceInfo(37, "Color & Distance Sensor", Kind.COLOR_DISTANCE),
    DeviceInfo(38, "BOOST Interactive Motor", Kind.MOTOR_REL),
    DeviceInfo(46, "Technic Large Motor", Kind.MOTOR_REL),
    DeviceInfo(47, "Technic XL Motor", Kind.MOTOR_REL),
    DeviceInfo(48, "Medium Angular Motor (Cyan)", Kind.MOTOR_ABS),
    DeviceInfo(49, "Large Angular Motor (Cyan)", Kind.MOTOR_ABS),
    DeviceInfo(61, "Color Sensor", Kind.COLOR),
    DeviceInfo(62, "Distance Sensor", Kind.DISTANCE),
    DeviceInfo(63, "Force Sensor", Kind.FORCE),
    DeviceInfo(64, "3x3 Color Light Matrix", Kind.MATRIX),
    DeviceInfo(65, "Small Angular Motor", Kind.MOTOR_ABS),
    DeviceInfo(75, "Medium Angular Motor (Grey)", Kind.MOTOR_ABS),
    DeviceInfo(76, "Large Angular Motor (Grey)", Kind.MOTOR_ABS),
]

CATALOG: dict[int, DeviceInfo] = {d.typeid: d for d in _DEVICES}

ENCODER_MOTORS = frozenset({Kind.MOTOR_ABS, Kind.MOTOR_REL})
ALL_MOTORS = ENCODER_MOTORS | {Kind.MOTOR_PASSIVE}

# capability -> (allowed kinds, what the user is told was expected)
CAPABILITIES: dict[str, tuple[frozenset, str]] = {
    "motor.degrees": (ENCODER_MOTORS, "motor with encoder"),
    "motor.seconds": (ALL_MOTORS, "motor"),
    "motor.power": (ALL_MOTORS, "motor"),
    "motor.position": (frozenset({Kind.MOTOR_ABS}), "motor with absolute position"),
    "light": (frozenset({Kind.LIGHT}), "Light"),
    "matrix": (frozenset({Kind.MATRIX}), "3x3 Color Light Matrix"),
    "distance_lights": (frozenset({Kind.DISTANCE}), "Distance Sensor"),
}


def lookup(typeid: int | None) -> DeviceInfo | None:
    if typeid is None:
        return None
    return CATALOG.get(typeid)


def check(capability: str, port: str, typeid: int | None) -> None:
    """Raise B3Error unless the device on `port` supports `capability`."""
    kinds, expected = CAPABILITIES[capability]
    if typeid is None:
        raise B3Error("no_device", f"Port {port}: expected {expected}, found nothing", port=port)
    info = lookup(typeid)
    if info is None:
        raise B3Error("wrong_device", f"Port {port}: expected {expected}, found unknown device {typeid}", port=port)
    if info.kind not in kinds:
        raise B3Error("wrong_device", f"Port {port}: expected {expected}, found {info.name}", port=port)
```

`hatd/b3hatd/backend.py`:
```python
"""Interface between hatd and the Build HAT hardware."""

from abc import ABC, abstractmethod


class HatBackend(ABC):
    """Hardware access. Speeds are -100..100 (positive = clockwise).

    Blocking motor methods return when the movement is finished and raise
    B3Error("interrupted") if motor_stop/stop_all stopped them first.
    """

    @abstractmethod
    async def start(self) -> None: ...

    @abstractmethod
    async def close(self) -> None: ...

    @abstractmethod
    def typeids(self) -> dict[str, int | None]: ...

    @abstractmethod
    async def read(self) -> dict[str, dict]: ...

    @abstractmethod
    async def vin(self) -> float: ...

    @abstractmethod
    async def motor_run_for_degrees(self, port: str, degrees: float, speed: int) -> None: ...

    @abstractmethod
    async def motor_run_for_seconds(self, port: str, seconds: float, speed: int) -> None: ...

    @abstractmethod
    async def motor_start(self, port: str, speed: int) -> None: ...

    @abstractmethod
    async def motor_stop(self, port: str) -> None: ...

    @abstractmethod
    async def motor_go_to(self, port: str, position: int, direction: str, speed: int) -> None: ...

    @abstractmethod
    async def light_set(self, port: str, brightness: int) -> None: ...

    @abstractmethod
    async def matrix_set(self, port: str, pixels: list[tuple[str, int]]) -> None: ...

    @abstractmethod
    async def sensor_lights(self, port: str, values: list[int]) -> None: ...

    @abstractmethod
    async def stop_all(self) -> None: ...
```

`hatd/b3hatd/sim.py`:
```python
"""In-memory Build HAT for tests and development without hardware."""

import asyncio

from .backend import HatBackend
from .devices import ALL_MOTORS, PORTS, Kind, lookup
from .errors import B3Error

DEFAULT_VALUES: dict[Kind, dict] = {
    Kind.MOTOR_ABS: {"position": 0, "aposition": 0, "speed": 0},
    Kind.MOTOR_REL: {"position": 0, "speed": 0},
    Kind.MOTOR_PASSIVE: {"power": 0},
    Kind.LIGHT: {"brightness": 0},
    Kind.MATRIX: {},
    Kind.COLOR: {"color": "none", "reflection": 0},
    Kind.DISTANCE: {"distance_mm": -1},
    Kind.FORCE: {"force_n": 0.0, "pressed": False},
    Kind.COLOR_DISTANCE: {"color": "none", "reflection": 0, "distance": 0},
    Kind.WEDO_TILT: {"tilt": [0, 0]},
    Kind.WEDO_MOTION: {"distance": 0},
}


def _wrap(angle: float) -> float:
    """Normalise to -180..179."""
    return ((angle + 180) % 360) - 180


class SimBackend(HatBackend):
    def __init__(self, max_dps: float = 1000.0, vin: float = 8.0):
        self.max_dps = max_dps
        self._vin = vin
        self._types: dict[str, int | None] = {p: None for p in PORTS}
        self._waiters: dict[str, set[asyncio.Event]] = {p: set() for p in PORTS}
        self.values: dict[str, dict] = {}
        self.calls: list[tuple] = []

    # --- test helpers -------------------------------------------------
    def attach(self, port: str, typeid: int, **values) -> None:
        self._types[port] = typeid
        info = lookup(typeid)
        base = dict(DEFAULT_VALUES[info.kind]) if info else {}
        base.update(values)
        self.values[port] = base

    def detach(self, port: str) -> None:
        self._types[port] = None
        self.values.pop(port, None)
        self._interrupt(port)

    def set_vin(self, vin: float) -> None:
        self._vin = vin

    # --- internals ----------------------------------------------------
    def _require(self, port: str) -> dict:
        if self._types[port] is None:
            raise B3Error("no_device", f"Port {port}: no device", port=port)
        return self.values[port]

    def _set_speed(self, port: str, speed: int) -> None:
        values = self.values.get(port, {})
        key = "power" if "power" in values else "speed"
        values[key] = speed

    def _interrupt(self, port: str) -> None:
        for ev in list(self._waiters[port]):
            ev.set()

    async def _wait(self, port: str, seconds: float) -> None:
        ev = asyncio.Event()
        self._waiters[port].add(ev)
        try:
            try:
                await asyncio.wait_for(ev.wait(), timeout=seconds)
            except asyncio.TimeoutError:
                return
            raise B3Error("interrupted", f"Port {port}: stopped", port=port)
        finally:
            self._waiters[port].discard(ev)

    def _move(self, port: str, delta: float) -> None:
        values = self.values[port]
        values["position"] += delta
        if "aposition" in values:
            values["aposition"] = _wrap(values["aposition"] + delta)

    def _duration(self, degrees: float, speed: int) -> float:
        return abs(degrees) / (abs(speed) / 100 * self.max_dps)

    # --- HatBackend ---------------------------------------------------
    async def start(self) -> None:
        pass

    async def close(self) -> None:
        pass

    def typeids(self) -> dict[str, int | None]:
        return dict(self._types)

    async def read(self) -> dict[str, dict]:
        return {p: dict(v) for p, v in self.values.items()}

    async def vin(self) -> float:
        return self._vin

    async def motor_run_for_degrees(self, port, degrees, speed):
        self._require(port)
        self.calls.append(("run_for_degrees", port, degrees, speed))
        self._set_speed(port, speed)
        await self._wait(port, self._duration(degrees, speed))
        self._move(port, degrees if speed > 0 else -degrees)
        self._set_speed(port, 0)

    async def motor_run_for_seconds(self, port, seconds, speed):
        self._require(port)
        self.calls.append(("run_for_seconds", port, seconds, speed))
        self._set_speed(port, speed)
        await self._wait(port, seconds)
        self._set_speed(port, 0)

    async def motor_start(self, port, speed):
        self._require(port)
        self.calls.append(("start", port, speed))
        self._set_speed(port, speed)

    async def motor_stop(self, port):
        self._require(port)
        self.calls.append(("stop", port))
        self._set_speed(port, 0)
        self._interrupt(port)

    async def motor_go_to(self, port, position, direction, speed):
        values = self._require(port)
        self.calls.append(("go_to", port, position, direction, speed))
        cw = (_wrap(position) - values["aposition"]) % 360
        if direction == "cw":
            delta = cw
        elif direction == "ccw":
            delta = cw - 360 if cw else 0
        else:
            delta = cw if cw <= 180 else cw - 360
        await self._wait(port, self._duration(delta, speed))
        self._move(port, delta)

    async def light_set(self, port, brightness):
        self._require(port)
        self.calls.append(("light_set", port, brightness))
        self.values[port]["brightness"] = brightness

    async def matrix_set(self, port, pixels):
        self._require(port)
        self.calls.append(("matrix_set", port, pixels))

    async def sensor_lights(self, port, values):
        self._require(port)
        self.calls.append(("sensor_lights", port, values))

        self.calls.append(("stop_all",))
        for port in PORTS:
            info = lookup(self._types[port])
            if info and info.kind in ALL_MOTORS:
                self._set_speed(port, 0)
```

```python
"""PIN login and session cookies."""

import secrets

from aiohttp import web

from .errors import B3Error
from .keys import CONFIG, SESSIONS

COOKIE = "b3session"


class Sessions:
    def __init__(self):
        self._tokens: set[str] = set()

    def create(self) -> str:
        token = secrets.token_hex(16)
        self._tokens.add(token)
        return token

    def valid(self, token: str | None) -> bool:
        return token is not None and token in self._tokens


@web.middleware
async def middleware(request: web.Request, handler):
    path = request.path
    if path.startswith("/api/") and path != "/api/login":
        if not request.app[SESSIONS].valid(request.cookies.get(COOKIE)):
            raise B3Error("unauthorized", "PIN required")
    return await handler(request)


async def login(request: web.Request) -> web.Response:
    try:
        body = await request.json()
    except ValueError:
        raise B3Error("bad_args", "JSON body required")
    pin = body.get("pin") if isinstance(body, dict) else None
    if not isinstance(pin, str) or not secrets.compare_digest(pin, request.app[CONFIG].pin):
        raise B3Error("unauthorized", "Wrong PIN")
    resp = web.json_response({"ok": True})
    resp.set_cookie(COOKIE, request.app[SESSIONS].create(), httponly=True, samesite="Strict")
    return resp
```

```python
"""Projects stored on the Pi as <id>.sb3 + <id>.json."""

import json
import os
import re
from datetime import datetime, timezone
from pathlib import Path

from aiohttp import web

from .errors import B3Error
from .keys import CONFIG, STORE

_ID = re.compile(r"^[0-9a-f]{32}$")


def _atomic_write(path: Path, data: bytes) -> None:
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_bytes(data)
    os.replace(tmp, path)


class ProjectStore:
    def __init__(self, root: Path):
        self.root = root
        root.mkdir(parents=True, exist_ok=True)

    def _paths(self, pid: str) -> tuple[Path, Path]:
        if not isinstance(pid, str) or not _ID.match(pid):
            raise B3Error("bad_args", "Invalid project id")
        return self.root / f"{pid}.sb3", self.root / f"{pid}.json"

    def list(self) -> list[dict]:
        items = []
        for meta_path in self.root.glob("*.json"):
            try:
                items.append(json.loads(meta_path.read_text()))
            except (OSError, ValueError):
                continue
        return sorted(items, key=lambda m: m["modified"], reverse=True)

    def get(self, pid: str) -> bytes:
        sb3, _ = self._paths(pid)
        if not sb3.exists():
            raise B3Error("not_found", "Project not found")
        return sb3.read_bytes()

    def put(self, pid: str, name: str, data: bytes) -> dict:
        sb3, meta_path = self._paths(pid)
        name = (name or "").strip()
        if not 1 <= len(name) <= 100:
            raise B3Error("bad_args", "Project name must be 1-100 characters")
        if not data.startswith(b"PK\x03\x04"):
            raise B3Error("bad_args", "Project must be an .sb3 (zip) file")
        meta = {
            "id": pid,
            "name": name,
            "modified": datetime.now(timezone.utc).isoformat(timespec="microseconds"),
        }
        _atomic_write(sb3, data)
        _atomic_write(meta_path, json.dumps(meta).encode())
        return meta

    def delete(self, pid: str) -> None:
        sb3, meta_path = self._paths(pid)
        if not sb3.exists():
            raise B3Error("not_found", "Project not found")
        sb3.unlink()
        meta_path.unlink(missing_ok=True)


async def _list(request: web.Request) -> web.Response:
    return web.json_response(request.app[STORE].list())


async def _get(request: web.Request) -> web.Response:
    data = request.app[STORE].get(request.match_info["pid"])
    return web.Response(body=data, content_type="application/zip")


async def _put(request: web.Request) -> web.Response:
    data = await request.read()
    meta = request.app[STORE].put(request.match_info["pid"], request.query.get("name", ""), data)
    return web.json_response(meta)


async def _delete(request: web.Request) -> web.Response:
    request.app[STORE].delete(request.match_info["pid"])
    return web.Response(status=204)


def setup(app: web.Application) -> None:
    app[STORE] = ProjectStore(app[CONFIG].data_dir / "projects")
    app.router.add_get("/api/projects", _list)
    app.router.add_get("/api/projects/{pid}", _get)
    app.router.add_put("/api/projects/{pid}", _put)
    app.router.add_delete("/api/projects/{pid}", _delete)
```

```python
"""Sine-wave WAV files for beep blocks."""

import math
import os
import struct
import wave
from pathlib import Path

RATE = 22050


def note_to_hz(note: int) -> float:
    """MIDI note number to frequency (69 = A4 = 440 Hz)."""
    return 440.0 * 2 ** ((note - 69) / 12)


def write_tone(path: Path, hz: float, seconds: float, rate: int = RATE) -> None:
    n = int(rate * seconds)
    step = 2 * math.pi * hz / rate
    frames = struct.pack(f"<{n}h", *(int(12000 * math.sin(step * i)) for i in range(n)))
    tmp = path.with_suffix(".tmp")
    with wave.open(str(tmp), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(rate)
        w.writeframes(frames)
    os.replace(tmp, path)
```

```python
"""Plays project sounds and beeps on the Pi's audio output via aplay."""

import asyncio
import hashlib
import os
import re
from pathlib import Path

from aiohttp import web

from .errors import B3Error
from .keys import SOUND
from .tone import note_to_hz, write_tone

_MD5 = re.compile(r"^[0-9a-f]{32}$")
BEEP_FOREVER_S = 30.0


class SubprocessRunner:
    async def spawn(self, args: list[str]):
        return await asyncio.create_subprocess_exec(
            *args, stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.DEVNULL)

    async def run(self, args: list[str]) -> int:
        proc = await self.spawn(args)
        return await proc.wait()


def _check_md5(md5: str) -> None:
    if not isinstance(md5, str) or not _MD5.match(md5):
        raise B3Error("bad_args", "Invalid sound id")


class SoundPlayer:
    def __init__(self, cache_dir: Path, runner=None, device: str | None = None,
                 mixer_card: str | None = None, mixer_control: str | None = None,
                 beep_forever_s: float = BEEP_FOREVER_S):
        self.cache_dir = cache_dir
        self.beep_forever_s = beep_forever_s
        cache_dir.mkdir(parents=True, exist_ok=True)
        self.runner = runner or SubprocessRunner()
        self.device = device
        self.mixer_card = mixer_card
        self.mixer_control = mixer_control
        self.volume = 100
        self._playing: set = set()
        self._reapers: set[asyncio.Task] = set()

    def _path(self, md5: str) -> Path:
        _check_md5(md5)
        return self.cache_dir / f"{md5}.wav"

    def has(self, md5: str) -> bool:
        return self._path(md5).exists()

    def store(self, md5: str, data: bytes) -> None:
        path = self._path(md5)
        if hashlib.md5(data).hexdigest() != md5:
            raise B3Error("bad_args", "Checksum mismatch")
        if not (data[:4] == b"RIFF" and data[8:12] == b"WAVE"):
            raise B3Error("bad_args", "Only WAV sounds are supported")
        tmp = path.with_suffix(".tmp")
        tmp.write_bytes(data)
        os.replace(tmp, path)

    async def play(self, md5: str, wait: bool) -> None:
        path = self._path(md5)
        if not path.exists():
            raise B3Error("not_found", f"Sound {md5} is not uploaded")
        await self._play(path, wait)

    async def beep(self, note: int, duration: float | None) -> None:
        seconds = duration if duration is not None else self.beep_forever_s
        path = self.cache_dir / f"beep-{note}-{int(round(seconds * 1000))}.wav"
        if not path.exists():
            await asyncio.to_thread(write_tone, path, note_to_hz(note), seconds)
        await self._play(path, wait=duration is not None)

    async def _play(self, path: Path, wait: bool) -> None:
        args = ["aplay", "-q"] + (["-D", self.device] if self.device else []) + [str(path)]
        proc = await self.runner.spawn(args)
        self._playing.add(proc)
        if wait:
            try:
                await proc.wait()
            finally:
                self._playing.discard(proc)
        else:
            task = asyncio.ensure_future(self._reap(proc))
            self._reapers.add(task)
            task.add_done_callback(self._reapers.discard)

    async def _reap(self, proc) -> None:
        try:
            await proc.wait()
        finally:
            self._playing.discard(proc)

    async def stop(self) -> None:
        for proc in list(self._playing):
            try:
                proc.kill()
            except ProcessLookupError:
                pass
        self._playing.clear()

    async def set_volume(self, value: int) -> None:
        self.volume = value
        if not self.mixer_control:
            return
        args = ["amixer", "-q"] + (["-c", self.mixer_card] if self.mixer_card else [])
        await self.runner.run(args + ["sset", self.mixer_control, f"{value}%"])


async def _put(request: web.Request) -> web.Response:
    request.app[SOUND].store(request.match_info["md5"], await request.read())
    return web.Response(status=204)


async def _head(request: web.Request) -> web.Response:
    return web.Response(status=200 if request.app[SOUND].has(request.match_info["md5"]) else 404)


def setup(app: web.Application) -> None:
    app.router.add_put("/api/sounds/{md5}", _put)
    app.router.add_head("/api/sounds/{md5}", _head)
```

```python
"""Only one client controls the robot; it must keep pinging."""

import asyncio
import time
from typing import Awaitable, Callable


class ControlManager:
    def __init__(self, stop_everything: Callable[[], Awaitable[None]],
                 on_change: Callable[[str | None], None] | None = None,
                 timeout: float = 3.0, clock: Callable[[], float] = time.monotonic):
        self._stop_everything = stop_everything
        self._on_change = on_change
        self.timeout = timeout
        self._clock = clock
        self.holder: str | None = None
        self._last_ping = 0.0

    def _changed(self) -> None:
        if self._on_change:
            self._on_change(self.holder)

    def claim(self, cid: str) -> None:
        self._last_ping = self._clock()
        if self.holder != cid:
            self.holder = cid
            self._changed()

    def is_controller(self, cid: str | None) -> bool:
        return cid is not None and cid == self.holder

    def ping(self, cid: str) -> None:
        if self.is_controller(cid):
            self._last_ping = self._clock()

    async def release(self, cid: str, stop: bool) -> None:
        if not self.is_controller(cid):
            return
        self.holder = None
        if stop:
            await self._stop_everything()
        self._changed()

    async def check(self) -> bool:
        if self.holder is None or self._clock() - self._last_ping <= self.timeout:
            return False
        await self.release(self.holder, stop=True)
        return True

    async def run(self, interval: float) -> None:
        while True:
            await asyncio.sleep(interval)
            await self.check()
```

```python
import asyncio
import itertools

from b3hatd.ws import API_VERSION

_ids = itertools.count(1)
_buffers: dict[int, list] = {}


async def open_ws(client):
    ws = await client.ws_connect("/api/ws")
    hello = await ws.receive_json(timeout=2)
    assert hello["type"] == "hello"
    await ws.send_json({"type": "hello", "api_version": API_VERSION})
    return ws, hello["client_id"]


async def _next(ws, pred, timeout):
    buf = _buffers.setdefault(id(ws), [])
    for i, msg in enumerate(buf):
        if pred(msg):
            return buf.pop(i)

    async def _find():
        while True:
            msg = await ws.receive_json()
            if pred(msg):
                return msg
            if msg["type"] != "telemetry":
                buf.append(msg)
    return await asyncio.wait_for(_find(), timeout)


async def next_of_type(ws, type_, timeout=2.0):
    return await _next(ws, lambda m: m["type"] == type_, timeout)


async def reply_for(ws, rid, timeout=2.0):
    return await _next(ws, lambda m: m["type"] == "reply" and m["id"] == rid, timeout)


async def call(ws, cmd, args=None, id=None, timeout=2.0):
    rid = id if id is not None else next(_ids)
    await ws.send_json({"id": rid, "cmd": cmd, "args": args or {}})
    return await reply_for(ws, rid, timeout)
```

```python
"""Connected WebSocket clients."""

from aiohttp import web


class Clients:
    def __init__(self):
        self._ws: dict[str, web.WebSocketResponse] = {}

    def add(self, cid: str, ws: web.WebSocketResponse) -> None:
        self._ws[cid] = ws

    def remove(self, cid: str) -> None:
        self._ws.pop(cid, None)

    def ids(self) -> list[str]:
        return list(self._ws)

    async def send(self, cid: str, msg: dict) -> None:
        ws = self._ws.get(cid)
        if ws is None or ws.closed:
            return
        try:
            await ws.send_json(msg)
        except (ConnectionResetError, RuntimeError):
            pass

    async def broadcast(self, msg: dict) -> None:
        for cid in self.ids():
            await self.send(cid, msg)
```

```python
"""WebSocket commands: validation and dispatch."""

import math
from dataclasses import dataclass
from typing import Awaitable, Callable

from aiohttp import web

from .devices import PORTS, check
from .errors import B3Error
from .keys import BACKEND, CONTROL, SOUND

Handler = Callable[["Context", dict], Awaitable[dict | None]]
_HANDLERS: dict[str, tuple[Handler, bool]] = {}


@dataclass
class Context:
    app: web.Application
    client_id: str

    @property
    def backend(self):
        return self.app[BACKEND]

    @property
    def sound(self):
        return self.app[SOUND]

    @property
    def control(self):
        return self.app[CONTROL]


def command(name: str, actuating: bool = True):
    def register(fn: Handler) -> Handler:
        _HANDLERS[name] = (fn, actuating)
        return fn
    return register


async def dispatch(ctx: Context, cmd: str, args: dict) -> dict:
    entry = _HANDLERS.get(cmd)
    if entry is None:
        raise B3Error("unknown_cmd", f"Unknown command {cmd}")
    fn, actuating = entry
    if actuating and not ctx.control.is_controller(ctx.client_id):
        raise B3Error("not_controller", "Another device controls the robot. Take control first.")
    result = await fn(ctx, args)
    return result if result is not None else {}


# --- validators -------------------------------------------------------

def port(args: dict, key: str = "port") -> str:
    value = args.get(key)
    if value not in PORTS:
        raise B3Error("bad_args", f"{key} must be one of A, B, C, D")
    return value


def number(args: dict, key: str, lo: float, hi: float, integer: bool = False):
    value = args.get(key)
    if (isinstance(value, bool) or not isinstance(value, (int, float))
            or not math.isfinite(value) or not lo <= value <= hi):
        raise B3Error("bad_args", f"{key} must be a number between {lo} and {hi}")
    if integer:
        if value != int(value):
            raise B3Error("bad_args", f"{key} must be a whole number")
        return int(value)
    return float(value)


def choice(args: dict, key: str, options: tuple[str, ...]) -> str:
    value = args.get(key)
    if value not in options:
        raise B3Error("bad_args", f"{key} must be one of {', '.join(options)}")
    return value


def boolean(args: dict, key: str) -> bool:
    value = args.get(key)
    if not isinstance(value, bool):
        raise B3Error("bad_args", f"{key} must be true or false")
    return value


def require(ctx: Context, capability: str, p: str) -> None:
    check(capability, p, ctx.backend.typeids()[p])


# --- session commands -------------------------------------------------

@command("ping", actuating=False)
async def _ping(ctx: Context, args: dict):
    ctx.control.ping(ctx.client_id)


@command("control.claim", actuating=False)
async def _claim(ctx: Context, args: dict):
    ctx.control.claim(ctx.client_id)
    return {"holder": ctx.client_id}
```

```python
"""WebSocket endpoint /api/ws."""

import asyncio
import json
import logging
import uuid

from aiohttp import WSMsgType, web

from . import commands
from .errors import B3Error
from .keys import CLIENTS, CONTROL

log = logging.getLogger(__name__)

API_VERSION = "1"


def _error(code: str, message: str) -> dict:
    return {"type": "error", "error": {"code": code, "message": message}}


async def _handle(app: web.Application, cid: str, data: dict) -> None:
    rid = data.get("id")
    try:
        cmd = data.get("cmd")
        args = data.get("args", {})
        if not isinstance(cmd, str):
            raise B3Error("bad_message", "Missing cmd")
        if not isinstance(args, dict):
            raise B3Error("bad_args", "args must be an object")
        result = await commands.dispatch(commands.Context(app, cid), cmd, args)
        reply = {"type": "reply", "id": rid, "ok": True, "result": result}
    except B3Error as e:
        reply = {"type": "reply", "id": rid, "ok": False, "error": e.to_dict()}
    except asyncio.CancelledError:
        raise
    except Exception:
        log.exception("command failed: %r", data)
        reply = {"type": "reply", "id": rid, "ok": False,
                 "error": {"code": "internal", "message": "Internal error"}}
    await app[CLIENTS].send(cid, reply)


async def handler(request: web.Request) -> web.WebSocketResponse:
    app = request.app
    ws = web.WebSocketResponse()
    await ws.prepare(request)
    cid = uuid.uuid4().hex
    clients = app[CLIENTS]
    control = app[CONTROL]
    clients.add(cid, ws)
    await clients.send(cid, {"type": "hello", "api_version": API_VERSION,
                             "client_id": cid, "control": {"holder": control.holder}})
    greeted = False
    tasks: set[asyncio.Task] = set()
    try:
        async for msg in ws:
            if msg.type != WSMsgType.TEXT:
                continue
            try:
                data = json.loads(msg.data)
            except ValueError:
                await clients.send(cid, _error("bad_message", "Invalid JSON"))
                continue
            if not isinstance(data, dict):
                await clients.send(cid, _error("bad_message", "Message must be an object"))
                continue
            if data.get("type") == "hello":
                if str(data.get("api_version", "")).split(".")[0] != API_VERSION:
                    await clients.send(cid, _error("bad_api_version",
                                                   f"hatd speaks API {API_VERSION}"))
                    await ws.close()
                    break
                greeted = True
                continue
            if not greeted:
                await clients.send(cid, _error("bad_message", "Send hello first"))
                continue
            task = asyncio.ensure_future(_handle(app, cid, data))
            tasks.add(task)
            task.add_done_callback(tasks.discard)
    finally:
        clients.remove(cid)
        for task in tasks:
            task.cancel()
        await control.release(cid, stop=True)
    return ws


def setup(app: web.Application) -> None:
    app.router.add_get("/api/ws", handler)
```

```python
    left, right = port(args, "left"), port(args, "right")
    if left == right:
        raise B3Error("bad_args", "left and right must be different ports")

async def _pair_run_for(ctx: Context, args: dict):
    left, right = _pair(args)
    unit = choice(args, "unit", _UNITS)
    wheels = []
    for side, p in (("left", left), ("right", right)):
        value = number(args, f"{side}_value", 0, _MAX_VALUE[unit])
        speed = _speed(args, f"{side}_speed")
        require(ctx, f"motor.{unit}", p)
        if value > 0 and speed != 0:

    await asyncio.gather(*(_run_for(ctx, p, unit, v, s) for p, v, s in wheels))
```

```python
"""Pushes port values (20 Hz) and device changes to all clients."""

import asyncio
import logging
from typing import Awaitable, Callable

from .backend import HatBackend
from .devices import PORTS, lookup

log = logging.getLogger(__name__)


def _describe(typeid: int | None) -> dict:
    if typeid is None:
        return {"typeid": None, "name": None, "kind": None}
    info = lookup(typeid)
    if info is None:
        return {"typeid": typeid, "name": f"Unknown device {typeid}", "kind": None}
    return {"typeid": typeid, "name": info.name, "kind": info.kind.value}


class TelemetryLoop:
    def __init__(self, backend: HatBackend, broadcast: Callable[[dict], Awaitable[None]],
                 interval: float = 0.05, vin_every: int = 20):
        self.backend = backend
        self.broadcast = broadcast
        self.interval = interval
        self.vin_every = vin_every
        self._known: dict[str, int | None] = {p: None for p in PORTS}
        self._steps = 0
        self._vin: float | None = None

    async def step(self) -> None:
        try:
            values = await self.backend.read()
            if self._steps % self.vin_every == 0:
                self._vin = await self.backend.vin()
        except Exception:
            log.exception("telemetry read failed")
            return
        finally:
            self._steps += 1
        types = self.backend.typeids()
        for p in PORTS:
            if types[p] != self._known[p]:
                self._known[p] = types[p]
                await self.broadcast({"type": "device", "port": p, **_describe(types[p])})
        ports = {}
        for p in PORTS:
            ports[p] = None if types[p] is None else {**_describe(types[p]), **values.get(p, {})}
        await self.broadcast({"type": "telemetry", "vin": self._vin, "ports": ports})

    async def run(self) -> None:
        while True:
            await self.step()
            await asyncio.sleep(self.interval)
```

`hatd/b3hatd/buildhat_backend.py`:
```python
"""HatBackend on top of the blocking `buildhat` library."""

import asyncio
import logging

from .backend import HatBackend
from .devices import ALL_MOTORS, PORTS, Kind, lookup
from .errors import B3Error

log = logging.getLogger(__name__)

_CLASS_FOR_KIND = {
    Kind.MOTOR_ABS: "Motor",
    Kind.MOTOR_REL: "Motor",
    Kind.MOTOR_PASSIVE: "PassiveMotor",
    Kind.LIGHT: "Light",
    Kind.MATRIX: "Matrix",
    Kind.COLOR: "ColorSensor",
    Kind.DISTANCE: "DistanceSensor",
    Kind.FORCE: "ForceSensor",
    Kind.COLOR_DISTANCE: "ColorDistanceSensor",
    Kind.WEDO_TILT: "TiltSensor",
    Kind.WEDO_MOTION: "MotionSensor",
}

_READERS = {
    Kind.MOTOR_ABS: lambda d: {"position": d.get_position(), "aposition": d.get_aposition(),
                               "speed": d.get_speed()},
    Kind.MOTOR_REL: lambda d: {"position": d.get_position(), "speed": d.get_speed()},
    Kind.MOTOR_PASSIVE: lambda d: {},
    Kind.LIGHT: lambda d: {},
    Kind.MATRIX: lambda d: {},
    Kind.COLOR: lambda d: {"color": d.get_color(), "reflection": d.get_reflected_light()},
    Kind.DISTANCE: lambda d: {"distance_mm": d.get_distance()},
    Kind.FORCE: lambda d: {"force_n": d.get_force(), "pressed": d.is_pressed()},
    Kind.COLOR_DISTANCE: lambda d: {"color": d.get_color(), "reflection": d.get_reflected_light(),
                                    "distance": d.get_distance()},
    Kind.WEDO_TILT: lambda d: {"tilt": list(d.get_tilt())},
    Kind.WEDO_MOTION: lambda d: {"distance": d.get_distance()},
}

_DIRECTIONS = {"shortest": "shortest", "cw": "clockwise", "ccw": "anticlockwise"}


class BuildHatBackend(HatBackend):
    def __init__(self):
        self._buildhat = None
        self._hat = None
        self._types: dict[str, int | None] = {p: None for p in PORTS}
        self._devices: dict[str, object] = {}
        self._kinds: dict[str, Kind] = {}
        self._generation: dict[str, int] = {p: 0 for p in PORTS}
        self._stops: dict[str, set[asyncio.Event]] = {p: set() for p in PORTS}
        self._lock = asyncio.Lock()

    async def start(self) -> None:
        import buildhat  # Pi only
        self._buildhat = buildhat
        self._hat = await asyncio.to_thread(buildhat.Hat)  # loads firmware on first run
        await self._refresh()

    async def close(self) -> None:
        self._devices.clear()

    # --- ports ------------------------------------------------------------
    def _open(self, port: str, kind: Kind):
        return getattr(self._buildhat, _CLASS_FOR_KIND[kind])(port)

    async def _refresh(self) -> None:
        async with self._lock:
            info = await asyncio.to_thread(self._hat.get)
            for p in PORTS:
                typeid = info[p]["typeid"]
                typeid = None if typeid == -1 else typeid
                if typeid == self._types[p]:
                    continue
                self._types[p] = typeid
                self._devices.pop(p, None)  # frees the port in buildhat (Device.__del__)
                self._kinds.pop(p, None)
                self._interrupt(p)
                dev_info = lookup(typeid)
                if dev_info is None:
                    continue
                try:
                    self._devices[p] = await asyncio.to_thread(self._open, p, dev_info.kind)
                    self._kinds[p] = dev_info.kind
                except Exception:
                    log.exception("cannot open %s on port %s", dev_info.name, p)

    def _require(self, port: str):
        dev = self._devices.get(port)
        if dev is None:
            raise B3Error("no_device", f"Port {port}: no device", port=port)
        return dev

    # --- interruption -----------------------------------------------------
    def _interrupt(self, port: str) -> None:
        self._generation[port] += 1
        for ev in list(self._stops[port]):
            ev.set()

    async def _blocking(self, port: str, fn, *args, **kwargs) -> None:
        """Run a blocking buildhat call; raise `interrupted` if stopped meanwhile."""
        gen = self._generation[port]
        stop = asyncio.Event()
        self._stops[port].add(stop)
        try:
            work = asyncio.ensure_future(asyncio.to_thread(fn, *args, **kwargs))
            work.add_done_callback(lambda f: f.cancelled() or f.exception())
            stopped = asyncio.ensure_future(stop.wait())
            await asyncio.wait({work, stopped}, return_when=asyncio.FIRST_COMPLETED)
            stopped.cancel()
            if self._generation[port] != gen:
                raise B3Error("interrupted", f"Port {port}: stopped", port=port)
            await work
        finally:
            self._stops[port].discard(stop)

    # --- HatBackend -------------------------------------------------------
    def typeids(self) -> dict[str, int | None]:
        return dict(self._types)

    async def read(self) -> dict[str, dict]:
        await self._refresh()
        devices = dict(self._devices)
        kinds = dict(self._kinds)

        def read_all() -> dict[str, dict]:
            out = {}
            for p, dev in devices.items():
                try:
                    out[p] = _READERS[kinds[p]](dev)
                except Exception as e:  # device unplugged between refresh and read
                    log.debug("read %s failed: %s", p, e)
            return out

        return await asyncio.to_thread(read_all)

    async def vin(self) -> float:
        return await asyncio.to_thread(self._hat.get_vin)

    async def motor_run_for_degrees(self, port, degrees, speed):
        dev = self._require(port)
        await self._blocking(port, dev.run_for_degrees, degrees, speed=speed, blocking=True)

    async def motor_run_for_seconds(self, port, seconds, speed):
        dev = self._require(port)
        if self._kinds[port] is Kind.MOTOR_PASSIVE:
            await asyncio.to_thread(dev.start, speed)
            stop = asyncio.Event()
            self._stops[port].add(stop)
            gen = self._generation[port]
            try:
                try:
                    await asyncio.wait_for(stop.wait(), timeout=seconds)
                except asyncio.TimeoutError:
                    pass
            finally:
                self._stops[port].discard(stop)
            await asyncio.to_thread(dev.stop)
            if self._generation[port] != gen:
                raise B3Error("interrupted", f"Port {port}: stopped", port=port)
            return
        await self._blocking(port, dev.run_for_seconds, seconds, speed=speed, blocking=True)

    async def motor_start(self, port, speed):
        dev = self._require(port)
        await asyncio.to_thread(dev.start, speed)

    async def motor_stop(self, port):
        dev = self._require(port)
        self._interrupt(port)
        await asyncio.to_thread(dev.stop)

    async def motor_go_to(self, port, position, direction, speed):
        dev = self._require(port)
        await self._blocking(port, dev.run_to_position, position, speed=speed, blocking=True,
                             direction=_DIRECTIONS[direction])

    async def light_set(self, port, brightness):
        dev = self._require(port)
        if brightness == 0:
            await asyncio.to_thread(dev.off)
        else:
            await asyncio.to_thread(dev.brightness, brightness)

    async def matrix_set(self, port, pixels):
        dev = self._require(port)
        rows = [pixels[0:3], pixels[3:6], pixels[6:9]]
        await asyncio.to_thread(dev.set_pixels, rows)

    async def sensor_lights(self, port, values):
        dev = self._require(port)
        await asyncio.to_thread(dev.eyes, *values)

    async def stop_all(self):
        for p in PORTS:
            self._interrupt(p)
            if self._kinds.get(p) in ALL_MOTORS:
                try:
                    await asyncio.to_thread(self._devices[p].stop)
                except Exception:
                    log.exception("stop %s failed", p)
```

```python
"""Simulates browsers: python3 -m b3hatd.loadcheck --url http://HOST:8080 --pin 1234 --clients 3 --seconds 60"""

import argparse
import asyncio
import time

import aiohttp

from .ws import API_VERSION


async def _client(session: aiohttp.ClientSession, base: str, seconds: float, controller: bool) -> float:
    count = 0
    async with session.ws_connect(f"{base}/api/ws") as ws:
        await ws.receive_json()
        await ws.send_json({"type": "hello", "api_version": API_VERSION})
        if controller:
            await ws.send_json({"id": 1, "cmd": "control.claim", "args": {}})
        start = time.monotonic()
        end = start + seconds
        next_ping = start + 1
        rid = 2
        while (now := time.monotonic()) < end:
            if controller and now >= next_ping:
                await ws.send_json({"id": rid, "cmd": "ping", "args": {}})
                rid += 1
                next_ping += 1
            try:
                msg = await ws.receive_json(timeout=min(0.5, end - now))
            except asyncio.TimeoutError:
                continue
            if msg["type"] == "telemetry":
                count += 1
    return count / seconds


async def loadcheck(base: str, pin: str, clients: int, seconds: float) -> list[float]:
    async with aiohttp.ClientSession(cookie_jar=aiohttp.CookieJar(unsafe=True)) as session:
        async with session.post(f"{base}/api/login", json={"pin": pin}) as resp:
            resp.raise_for_status()
        return list(await asyncio.gather(
            *(_client(session, base, seconds, i == 0) for i in range(clients))))


def main() -> None:
    parser = argparse.ArgumentParser(prog="b3hatd.loadcheck")
    parser.add_argument("--url", required=True)
    parser.add_argument("--pin", required=True)
    parser.add_argument("--clients", type=int, default=3)
    parser.add_argument("--seconds", type=float, default=60)
    args = parser.parse_args()
    rates = asyncio.run(loadcheck(args.url.rstrip("/"), args.pin, args.clients, args.seconds))
    for i, rate in enumerate(rates):
        print(f"client {i}: {rate:.1f} telemetry msg/s")


if __name__ == "__main__":
    main()
```
