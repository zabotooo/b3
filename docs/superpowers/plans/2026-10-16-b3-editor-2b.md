# B3 Editor, part B (Plan 2b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the B3 editor's V1 block set and project handling. Add the Light category (Distance Sensor lights, 3×3 Color Light Matrix, Light 88005) and the Sound category, which plays on the Pi. Add WeDo 2.0 tilt and motion blocks, a project library on the Pi with export and import, and a Sounds tab. Clean up the menu bar so no Scratch community features remain, and fix the polish items deferred from Plan 2a.

**Architecture:** Each new block family follows the Plan 2a pattern. It is a scratch-vm extension in `editor/packages/scratch-vm/src/extensions/b3/`, and its id is the SPIKE opcode prefix (`flipperlight`, `flippersound`), or a `b3*` prefix for blocks SPIKE does not have (`b3light`, `b3events`, `b3sensors`). Every extension talks to `hatd` through the shared `B3Hub`. Sounds are converted in the browser to 16-bit PCM WAV, uploaded once to `hatd`'s sound cache (`PUT /api/sounds/{md5}`), and then played with `sound.play`. Projects are saved as `.sb3` to `hatd`'s REST API by a B3 container in scratch-gui; Scratch's server-oriented project saver is bypassed. `hatd` gets two development aids: a `--sim-devices` option and a silent sound runner for `--sim`.

**Tech Stack:**
- Node 24.21.0 (via nvm) and npm workspaces.
- scratch-vm in CommonJS, tested with `tap`.
- scratch-gui with React and Redux, tested with Jest and @testing-library.
- Playwright (Chromium is already installed in `~/.cache/ms-playwright`).
- `hatd` in Python 3, tested with pytest; `.venv` lives in `hatd/.venv`.

**Spec:** `docs/superpowers/specs/2026-10-14-b3-design.md`. Previous plans are `docs/superpowers/plans/2026-10-14-b3-hatd.md` (Plan 1) and `docs/superpowers/plans/2026-10-14-b3-editor-2a.md` (Plan 2a).

## Global Constraints

- **Branding and language.**
  - License is AGPL-3.0 and the product name is "B3".
  - Never show the "Scratch", "LEGO" or "SPIKE" names or logos in the UI.
  - The UI is in English only. Write B3 strings as plain English in JSX; no translation files.
- **Node.** Every shell command that runs node or npm starts with `export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 24.21.0 >/dev/null;`, written below as `<nvm>`. From the repo root, `.superpowers/tools/n <cmd>` does the same.
- **Opcodes.** Extension ids match `/^[a-z0-9]+$/i`, and the final opcode is `<extensionId>_<opcode>`. Opcodes reuse SPIKE names from spec Appendix A; blocks SPIKE lacks use `b3light_*`, `b3events_*` and `b3sensors_*`.
- **Ports and errors.**
  - Ports are `A`–`D`.
  - Device problems give `Port X: expected <Device>, found <name|nothing>`, and the program stops (`requireDevice` / `fail` in `run.js`).
  - `interrupted` replies are silent.
  - Hats never fail; they return false when the device is missing.
- **hatd WebSocket API v1, exactly as implemented in `hatd/b3hatd/commands.py`:**
  - `light.set {port, brightness: int 0..100}` needs a Light (kind `light`).
  - `matrix.set {port, pixels}` needs a matrix (kind `matrix`). `pixels` is a list of exactly 9 `[colorName, brightness int 0..10]` in row-major order, top row first. `colorName` is one of `black pink lilac blue cyan turquoise green yellow orange red white`.
  - `sensor.lights {port, values: [4 × int 0..100]}` needs a Distance Sensor (kind `distance`). The order is buildhat's `eyes()` order: sensor's right-upper, left-upper, right-lower, left-lower, which seen from the front is top-left, top-right, bottom-left, bottom-right.
  - `sound.play {md5: 32 lowercase hex, wait: bool}` returns `not_found` when the md5 is not in the cache. With `wait: true` it replies when the sound ends.
  - `sound.beep {note: int 44..123, duration?: number 0.01..60}`. Without `duration` the beep lasts 30 s and the reply is immediate.
  - `sound.stop {}`.
  - `sound.volume {value: int 0..100}`.
  - All of these are actuating commands and need control.
- **hatd REST (session cookie `b3session`, `credentials: 'same-origin'`):**
  - `HEAD /api/sounds/{md5}` returns 200 when the sound is cached, 404 when it is not.
  - `PUT /api/sounds/{md5}` takes raw WAV bytes. It returns 204. It answers 400 when the md5 does not match the WAV bytes ("Checksum mismatch") or the body is not RIFF/WAVE ("Only WAV sounds are supported").
  - `GET /api/projects` returns `[{id, name, modified}]`, newest first.
  - `GET /api/projects/{id}` returns raw `.sb3` bytes.
  - `PUT /api/projects/{id}?name=<1..100 chars>` takes raw `.sb3` bytes and returns 200 with the meta.
  - `DELETE /api/projects/{id}` returns 204, or 404 if the project does not exist.
  - Project ids are 32 lowercase hex characters chosen by the client.
  - Errors come back as `{"error": {"code", "message"}}`.
- **Device kinds in telemetry:** `motor_abs motor_rel motor_passive light matrix color distance force color_distance wedo_tilt wedo_motion`.
  - The Light reports `brightness` (the last commanded value).
  - The matrix reports nothing.
  - WeDo tilt reports `tilt: [x, y]`.
  - WeDo motion reports `distance` (a raw number).
- **No network access to Scratch servers at runtime.** The sound library and the "Surprise" sound are removed, because they download from `assets.scratch.mit.edu`. No analytics.
- **The Pi.** Nothing is built on the Pi. Pi 4 work is allowed without asking only inside `~/b3-dev` (deploy, tests, a temporary hatd). Everything else on the Pi needs the user's consent. Stop a temporary hatd with `pkill -f "b3hat[d] --confi[g]"`; the brackets keep `pkill` from matching its own shell.
- **Builds.**
  - GUI Jest tests load scratch-vm from `packages/scratch-vm/dist`, so run `npm run build --workspace @scratch/scratch-vm` (from `editor/`) after VM changes and before GUI tests that load the VM.
  - The GUI webpack build (`npm run build:dev` in scratch-gui) bundles the VM from `src`.
- **End-to-end tests.**
  - They run against `hatd --sim`, started with `cd hatd && .venv/bin/python -m b3hatd --config ../.superpowers/dev/config.toml --sim [--sim-devices …]`.
  - Run them with `B3_URL=http://localhost:8080 B3_MOTOR=A npx playwright test -c test/b3-e2e/playwright.config.mjs` in scratch-gui.
  - The default sim ports are A=48, B=48, C=61, D=62.

```python
import argparse
import logging
from pathlib import Path

from aiohttp import web

from .app import create_app
from .config import load_config
from .devices import PORTS
from .sound import SoundPlayer

SIM_DEVICES = "A=48,B=48,C=61,D=62"


def parse_sim_devices(text: str) -> dict[str, int]:
    """'A=48, B=8' -> {'A': 48, 'B': 8}; ports not named stay empty."""
    devices: dict[str, int] = {}
    for item in filter(None, (part.strip() for part in text.split(","))):
        port, sep, typeid = item.partition("=")
        port = port.strip()
        if not sep or port not in PORTS or not typeid.strip().isdigit():
            raise ValueError(f"bad --sim-devices entry {item!r}; expected e.g. A=48")
        devices[port] = int(typeid)
    return devices


def build(config_path: Path, sim: bool, sim_devices: str = SIM_DEVICES) -> web.Application:
    config = load_config(config_path)
    runner = None
    if sim:
        from .sim import SilentRunner, SimBackend
        backend = SimBackend()
        for port, typeid in parse_sim_devices(sim_devices).items():
            backend.attach(port, typeid)
        runner = SilentRunner()
    else:
        from .buildhat_backend import BuildHatBackend
        backend = BuildHatBackend()
    sound = SoundPlayer(config.data_dir / "sounds", runner=runner, device=config.audio_device,
                        mixer_card=config.mixer_card, mixer_control=config.mixer_control)
    return create_app(config, backend, sound)


def main(argv: list[str] | None = None) -> None:
    parser = argparse.ArgumentParser(prog="b3hatd")
    parser.add_argument("--config", type=Path, default=Path("/var/lib/b3/config.toml"))
    parser.add_argument("--sim", action="store_true", help="use the simulator instead of a Build HAT")
    parser.add_argument("--sim-devices", default=SIM_DEVICES,
                        help=f"simulated devices as PORT=typeid list (default {SIM_DEVICES})")
    args = parser.parse_args(argv)
    try:
        parse_sim_devices(args.sim_devices)
    except ValueError as e:
        parser.error(str(e))
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s: %(message)s")
    config = load_config(args.config)
    web.run_app(build(args.config, args.sim, args.sim_devices), host=config.http_host, port=config.http_port)
```

```js
const md5 = require('js-md5');

const text = (bytes, start, end) => String.fromCharCode(...bytes.subarray(start, end));

/**
 * hatd plays sounds with aplay and accepts only RIFF/WAVE files; this checks for the
 * 16-bit PCM kind aplay always plays (Scratch also uses ADPCM WAV and MP3).
 * @param {Uint8Array} bytes - file contents
 * @returns {boolean} true for a 16-bit PCM WAV whose first chunk is "fmt "
 */
const isPcmWav = bytes => bytes.length >= 44 &&
    text(bytes, 0, 4) === 'RIFF' && text(bytes, 8, 16) === 'WAVEfmt ' &&
    bytes[20] === 1 && bytes[21] === 0 && bytes[34] === 16 && bytes[35] === 0;

/**
 * @param {Float32Array[]} channels - samples -1..1, one array per channel, equal lengths
 * @param {number} sampleRate - samples per second
 * @returns {Uint8Array} a 16-bit PCM WAV file
 */
const encodeWav = (channels, sampleRate) => {
    const count = channels.length;
    const frames = channels[0].length;
    const dataSize = frames * count * 2;
    const bytes = new Uint8Array(44 + dataSize);
    const view = new DataView(bytes.buffer);
    const writeText = (offset, s) => {
        for (let i = 0; i < s.length; i++) view.setUint8(offset + i, s.charCodeAt(i));
    };
    writeText(0, 'RIFF');
    view.setUint32(4, 36 + dataSize, true);
    writeText(8, 'WAVEfmt ');
    view.setUint32(16, 16, true);
    view.setUint16(20, 1, true);
    view.setUint16(22, count, true);
    view.setUint32(24, sampleRate, true);
    view.setUint32(28, sampleRate * count * 2, true);
    view.setUint16(32, count * 2, true);
    view.setUint16(34, 16, true);
    writeText(36, 'data');
    view.setUint32(40, dataSize, true);
    let offset = 44;
    for (let frame = 0; frame < frames; frame++) {
        for (let c = 0; c < count; c++) {
            const s = Math.max(-1, Math.min(1, channels[c][frame]));
            view.setInt16(offset, s < 0 ? s * 0x8000 : s * 0x7fff, true);
            offset += 2;
        }
    }
    return bytes;
};

/**
 * The sound as a WAV hatd can play: PCM WAV as is, anything else decoded and re-encoded.
 * @param {{data: Uint8Array}} asset - the sound's storage asset
 * @param {function(ArrayBuffer): Promise<object>} decode - e.g. AudioContext#decodeAudioData
 * @returns {Promise<Uint8Array>} 16-bit PCM WAV bytes
 */
const toPlayableWav = async (asset, decode) => {
    if (isPcmWav(asset.data)) return asset.data;
    const audio = await decode(asset.data.slice().buffer); // decodeAudioData detaches its input
    const channels = [];
    for (let c = 0; c < audio.numberOfChannels; c++) channels.push(audio.getChannelData(c));
    return encodeWav(channels, audio.sampleRate);
};

const wavMd5 = bytes => md5(bytes);

module.exports = {isPcmWav, encodeWav, toPlayableWav, wavMd5};
```

```js
const ArgumentType = require('../../extension-support/argument-type');
const BlockType = require('../../extension-support/block-type');
const Cast = require('../../util/cast');
const {getHub} = require('./hub');
const {fail, report, send} = require('./run');
const {COLORS} = require('./menus');
const {toPlayableWav, wavMd5} = require('./wav');

const clampNote = value => Math.min(123, Math.max(44, Math.round(Cast.toNumber(value))));

class Scratch3FlipperSound {
    constructor (runtime) {
        this.runtime = runtime;
        this.hub = getHub(runtime);
        this._wavs = new WeakMap(); // sound asset -> Promise<{bytes, md5}>
        this.decode = buffer => runtime.audioEngine.audioContext.decodeAudioData(buffer);
        this._redirectVolume();
        runtime.on('PROJECT_START', () => {
            const stage = runtime.getTargetForStage();
            if (stage && this.hub.isController) {
                this.hub.request('sound.volume', {value: Math.round(stage.volume)}).catch(() => {});
            }
        });
    }

    // Scratch's volume blocks keep their own value (the "volume" reporter) and set the Pi's too.
    _redirectVolume () {
        const primitives = this.runtime._primitives;
        for (const opcode of ['sound_setvolumeto', 'sound_changevolumeby']) {
            const scratch = primitives[opcode];
            if (!scratch) continue;
            primitives[opcode] = (args, util) => Promise.resolve(scratch(args, util))
                .then(() => send(this.hub, util, 'sound.volume', {value: Math.round(util.target.volume)}));
        }
    }

    getInfo () {
        const soundArg = {type: ArgumentType.STRING, menu: 'SOUND', defaultValue: 'pop'};
        return {
            id: 'flippersound',
            name: 'Sound',
            color1: COLORS.sound[0],
            color2: COLORS.sound[1],
            color3: COLORS.sound[2],
            blocks: [
                {opcode: 'playSoundUntilDone',
                    blockType: BlockType.COMMAND,
                    text: 'play sound [SOUND] until done',
                    arguments: {SOUND: soundArg}},
                {opcode: 'playSound',
                    blockType: BlockType.COMMAND,
                    text: 'start sound [SOUND]',
                    arguments: {SOUND: soundArg}},
                {opcode: 'stopSound', blockType: BlockType.COMMAND, text: 'stop all sounds'},
                '---',
                {opcode: 'beepForTime',
                    blockType: BlockType.COMMAND,
                    text: 'play beep [NOTE] for [DURATION] seconds',
                    arguments: {NOTE: {type: ArgumentType.NUMBER, defaultValue: 60},
                        DURATION: {type: ArgumentType.NUMBER, defaultValue: 0.2}}},
                {opcode: 'beep',
                    blockType: BlockType.COMMAND,
                    text: 'start playing beep [NOTE]',
                    arguments: {NOTE: {type: ArgumentType.NUMBER, defaultValue: 60}}}
            ],
            menus: {
                SOUND: {acceptReporters: true, items: 'getSoundMenu'}
            }
        };
    }

    _sounds () {
        const stage = this.runtime.getTargetForStage();
        return (stage && stage.sprite.sounds) || [];
    }

    getSoundMenu () {
        const names = this._sounds().map(sound => sound.name);
        return names.length ? names : [''];
    }

    // By name first, then as a 1-based number, like Scratch's sound blocks.
    _findSound (value) {
        const sounds = this._sounds();
        const byName = sounds.find(sound => sound.name === String(value));
        if (byName) return byName;
        const index = Math.round(Cast.toNumber(value));
        return Number.isInteger(index) && index >= 1 && index <= sounds.length ? sounds[index - 1] : null;
    }

    _prepare (asset) {
        let ready = this._wavs.get(asset);
        if (!ready) {
            ready = toPlayableWav(asset, this.decode).then(bytes => ({bytes, md5: wavMd5(bytes)}));
            this._wavs.set(asset, ready);
        }
        return ready;
    }

    async _play (args, util, wait) {
        const sound = this._findSound(args.SOUND);
        if (!sound || !sound.asset) return;
        let wav;
        try {
            wav = await this._prepare(sound.asset);
            await this.hub.uploadSound(wav.md5, wav.bytes);
        } catch (error) {
            fail(this.hub, util, `Sound "${sound.name}": ${error.message}`);
            return;
        }
        const play = () => this.hub.request('sound.play', {md5: wav.md5, wait});
        return play()
            .catch(error => {
                if (error.code !== 'not_found') throw error;
                this.hub.forgetSound(wav.md5); // hatd's cache was cleared since the upload
                return this.hub.uploadSound(wav.md5, wav.bytes).then(play);
            })
            .catch(error => report(this.hub, util, error));
    }

    playSoundUntilDone (args, util) {
        return this._play(args, util, true);
    }

    playSound (args, util) {
        return this._play(args, util, false);
    }

    stopSound (args, util) {
        return send(this.hub, util, 'sound.stop');
    }

    beepForTime (args, util) {
        const duration = Math.min(60, Cast.toNumber(args.DURATION));
        if (!(duration > 0)) return;
        return send(this.hub, util, 'sound.beep', {note: clampNote(args.NOTE), duration: Math.max(0.01, duration)});
    }

    beep (args, util) {
        return send(this.hub, util, 'sound.beep', {note: clampNote(args.NOTE)});
    }
}

module.exports = Scratch3FlipperSound;
```

```js
/**
 * State of a SPIKE 3×3 Color Light Matrix. hatd's matrix.set needs all nine pixels every
 * time, so the editor keeps the image, the brightness and the orientation per port.
 * Pixels are row-major, top row first, as hatd expects.
 */

const MATRIX_COLORS = ['black', 'pink', 'lilac', 'blue', 'cyan', 'turquoise',
    'green', 'yellow', 'orange', 'red', 'white'];
// One letter per colour for patterns typed as text; k (black) is off.
const LETTERS = {k: 'black', p: 'pink', l: 'lilac', b: 'blue', c: 'cyan', t: 'turquoise',
    g: 'green', y: 'yellow', o: 'orange', r: 'red', w: 'white'};
const ORIENTATIONS = ['upright', 'right', 'upsidedown', 'left']; // quarter turns clockwise

const blank = () => Array.from({length: 9}, () => ({color: 'black', level: 0}));
const newMatrix = () => ({pixels: blank(), brightness: 100, orientation: 'upright'});

const parsePattern = text => {
    const letters = [...String(text).toLowerCase()
        .replace(/[\s,]/g, '')];
    if (letters.length !== 9 || letters.some(ch => !LETTERS[ch])) return null;
    return letters.map(ch => LETTERS[ch]);
};

const showPattern = (matrix, colors) => {
    matrix.pixels = colors.map(color => ({color, level: color === 'black' ? 0 : 100}));
};

const clear = matrix => {
    matrix.pixels = blank();
};

const setPixel = (matrix, x, y, color, level) => {
    const column = Math.round(x);
    const row = Math.round(y);
    if (!(column >= 1 && column <= 3 && row >= 1 && row <= 3) || !MATRIX_COLORS.includes(color)) return false;
    matrix.pixels[((row - 1) * 3) + (column - 1)] = {color, level: Math.min(100, Math.max(0, Math.round(level)))};
    return true;
};

// new[row][col] = old[2 - col][row]
const turnClockwise = pixels => [6, 3, 0, 7, 4, 1, 8, 5, 2].map(i => pixels[i]);

const rotate = (matrix, direction) => {
    const turns = direction === 'counterclockwise' ? 3 : 1;
    for (let i = 0; i < turns; i++) matrix.pixels = turnClockwise(matrix.pixels);
};

const render = matrix => {
    let shown = matrix.pixels;
    for (let i = 0; i < ORIENTATIONS.indexOf(matrix.orientation); i++) shown = turnClockwise(shown);
    return shown.map(({color, level}) => [color, Math.round(level * matrix.brightness / 1000)]);
};

module.exports = {MATRIX_COLORS, ORIENTATIONS, newMatrix, parsePattern, showPattern, clear, setPixel, rotate, render};
```

```js
        const values = String(args.VALUE).trim()

            .slice(0, 4)
            .map(clamp100);

        return send(this.hub, util, 'sensor.lights', {port: args.PORT, values});

        if (!requireDevice(this.hub, util, port, ['matrix'], '3x3 Color Light Matrix')) return null;
        if (!this.matrices[port]) this.matrices[port] = M.newMatrix();
        return this.matrices[port];
    }

    _show (port, util) {
        return send(this.hub, util, 'matrix.set', {port, pixels: M.render(this.matrices[port])});
    }

    _pattern (args, util) {
        const colors = M.parsePattern(args.PATTERN);
        if (!colors) {
            fail(this.hub, util,
                `Port ${args.PORT}: pattern "${args.PATTERN}" must be 9 colour letters (k p l b c t g y o r w)`,
                args.PORT);
        }
        return colors;

        const matrix = this._matrix(args.PORT, util);
        const colors = matrix && this._pattern(args, util);
        if (!colors) return;
        M.showPattern(matrix, colors);
        return this._show(args.PORT, util);
    }

    // Waits on the thread's stack timer like Scratch's "wait": Stop kills the thread, so
    // the "off" frame never runs after Stop.
    lightColorMatrixImageOnForTime (args, util) {
        if (util.stackTimerNeedsInit()) {
            const matrix = this._matrix(args.PORT, util);
            const colors = matrix && this._pattern(args, util);
            if (!colors) return;
            M.showPattern(matrix, colors);
            this._show(args.PORT, util); // not awaited: the block waits on its timer
            util.startStackTimer(Math.max(0, Cast.toNumber(args.DURATION)) * 1000);
            util.yield();
        } else if (!util.stackTimerFinished()) {
            util.yield();
        } else {
            M.clear(this.matrices[args.PORT]);
            return this._show(args.PORT, util);
        }
    }

    lightColorMatrixOff (args, util) {
        const matrix = this._matrix(args.PORT, util);
        if (!matrix) return;
        M.clear(matrix);
        return this._show(args.PORT, util);
    }

    lightColorMatrixSetPixel (args, util) {
        const matrix = this._matrix(args.PORT, util);
        if (!matrix) return;
        const color = String(args.COLOR).toLowerCase();
        if (!M.setPixel(matrix, Cast.toNumber(args.X), Cast.toNumber(args.Y), color, Cast.toNumber(args.BRIGHTNESS))) {
            return;
        }
        return this._show(args.PORT, util);
    }

    lightColorMatrixSetBrightness (args, util) {
        const matrix = this._matrix(args.PORT, util);
        if (!matrix) return;
        matrix.brightness = clamp100(args.BRIGHTNESS);
        return this._show(args.PORT, util);
    }

    lightColorMatrixRotate (args, util) {
        const matrix = this._matrix(args.PORT, util);
        if (!matrix) return;
        M.rotate(matrix, args.DIRECTION);
        return this._show(args.PORT, util);
    }

    lightColorMatrixSetOrientation (args, util) {
        const matrix = this._matrix(args.PORT, util);
        if (!matrix || !M.ORIENTATIONS.includes(args.ORIENTATION)) return;
        matrix.orientation = args.ORIENTATION;
        return this._show(args.PORT, util);
    }
}
```

```js
/**
 * WeDo 2.0 Tilt Sensor: hatd reports buildhat's mode 0 as tilt [x, y] in degrees.
 * Which sign means forward/right has not been checked on hardware yet; if the blocks
 * report the opposite direction, swap the signs here.
 */
const TILT_THRESHOLD = 10;

const TILT_MENU = {acceptReporters: false, items: ['forward', 'backward', 'left', 'right', 'any']};

const tiltDirection = tilt => {
    const [x, y] = Array.isArray(tilt) ? tilt.map(Number) : [0, 0];
    if (Math.max(Math.abs(x), Math.abs(y)) < TILT_THRESHOLD) return 'level';
    if (Math.abs(y) >= Math.abs(x)) return y > 0 ? 'forward' : 'backward';
    return x > 0 ? 'right' : 'left';
};

const isTiltedAs = (tilt, option) => {
    const direction = tiltDirection(tilt);
    return option === 'any' ? direction !== 'level' : direction === option;
};

module.exports = {TILT_THRESHOLD, TILT_MENU, tiltDirection, isTiltedAs};
```

```jsx
import PropTypes from 'prop-types';
import React from 'react';
import {connect} from 'react-redux';
import B3ProjectLibrary from '../components/b3-project-library/b3-project-library.jsx';
import {closeB3Library} from '../reducers/b3-projects';
import {setProjectTitle} from '../reducers/project-title';
import {setProjectUnchanged} from '../reducers/project-changed';
import {closeAlertWithId, showAlertWithTimeout, showStandardAlert} from '../reducers/alerts';
import {deleteProject, listProjects, newProjectId, projectName, readProject, writeProject}
    from '../lib/b3-projects';

/** Save, open and delete projects on the Pi. Which robot project is open lives here. */
class B3Projects extends React.Component {
    constructor (props) {
        super(props);
        this.state = {projects: null, error: null};
        this.projectId = null; // id on the Pi of the open project; null until saved or opened
        this.openingId = null;
        this.handleProjectLoaded = () => {
            this.projectId = this.openingId; // New and "Load from your computer" clear it
            this.openingId = null;
        };
        this.handleOpen = project => this.open(project);
        this.handleDelete = project => this.remove(project);
    }

    componentDidMount () {
        this.props.vm.runtime.on('PROJECT_LOADED', this.handleProjectLoaded);
    }

    componentDidUpdate (prevProps) {
        if (this.props.saveRequests !== prevProps.saveRequests) this.save();
        if (this.props.libraryOpen && !prevProps.libraryOpen) this.refresh();
    }

    componentWillUnmount () {
        this.props.vm.runtime.removeListener('PROJECT_LOADED', this.handleProjectLoaded);
    }

    refresh () {
        this.setState({projects: null, error: null});
        return listProjects().then(projects => this.setState({projects}), e => this.setState({error: e.message}));
    }

    async save () {
        const id = this.projectId || newProjectId();
        this.props.onSaving();
        try {
            const sb3 = await this.props.vm.saveProjectSb3();
            await writeProject(id, projectName(this.props.projectTitle), sb3);
            this.projectId = id;
            this.props.onSaved();
        } catch (e) {
            this.props.onSaveFailed();
        }
    }

    async open (project) {
        if (this.props.projectChanged &&
            !window.confirm('Replace the current project? Unsaved changes will be lost.')) return; // eslint-disable-line no-alert
        try {
            const data = await readProject(project.id);
            this.openingId = project.id;
            await this.props.vm.loadProject(data);
            this.props.onOpened(project.name);
        } catch (e) {
            this.openingId = null;
            this.setState({error: e.message});
        }
    }

    async remove (project) {
        if (!window.confirm(`Delete "${project.name}" from the robot?`)) return; // eslint-disable-line no-alert
        try {
            await deleteProject(project.id);
            if (project.id === this.projectId) this.projectId = null;
            await this.refresh();
        } catch (e) {
            this.setState({error: e.message});
        }
    }

    render () {
        if (!this.props.libraryOpen) return null;
        return (
            <B3ProjectLibrary
                error={this.state.error}
                projects={this.state.projects}
                onClose={this.props.onClose}
                onDelete={this.handleDelete}
                onOpen={this.handleOpen}
            />
        );
    }
}

B3Projects.propTypes = {
    libraryOpen: PropTypes.bool,
    projectChanged: PropTypes.bool,
    projectTitle: PropTypes.string,
    saveRequests: PropTypes.number,
    vm: PropTypes.shape({
        loadProject: PropTypes.func,
        saveProjectSb3: PropTypes.func,
        runtime: PropTypes.object // eslint-disable-line react/forbid-prop-types
    }).isRequired,
    onClose: PropTypes.func.isRequired,
    onOpened: PropTypes.func.isRequired,
    onSaveFailed: PropTypes.func.isRequired,
    onSaved: PropTypes.func.isRequired,
    onSaving: PropTypes.func.isRequired
};

const mapStateToProps = state => ({
    libraryOpen: state.scratchGui.b3Projects.libraryOpen,
    saveRequests: state.scratchGui.b3Projects.saveRequests,
    projectChanged: state.scratchGui.projectChanged,
    projectTitle: state.scratchGui.projectTitle
});

const mapDispatchToProps = dispatch => ({
    onClose: () => dispatch(closeB3Library()),
    onOpened: name => {
        dispatch(setProjectTitle(name));
        dispatch(setProjectUnchanged());
        dispatch(closeB3Library());
    },
    onSaving: () => dispatch(showStandardAlert('saving')),
    onSaved: () => {
        dispatch(closeAlertWithId('saving'));
        dispatch(setProjectUnchanged());
        showAlertWithTimeout(dispatch, 'saveSuccess');
    },
    onSaveFailed: () => {
        dispatch(closeAlertWithId('saving'));
        dispatch(showStandardAlert('savingError'));
    }
});

export default connect(mapStateToProps, mapDispatchToProps)(B3Projects);
```
