# B3 Editor, part A (Plan 2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A B3 editor in the browser — Scratch fork without stage/sprites, connected to `hatd` (PIN, control, Run/Stop, port bar) — with the SPIKE word-block categories Motors, Movement, Events, Control, Sensors and the `is between` operator, driving the real Build HAT.

**Architecture:** The Scratch editor monorepo is imported into `editor/` with `git subtree --squash`. All B3 runtime code lives in `editor/packages/scratch-vm/src/extensions/b3/`: one `B3Hub` per VM (WebSocket client to `hatd`, telemetry cache, program state) shared by six extensions whose ids equal SPIKE's opcode prefixes (`flippermotor`, `flippermove`, `flipperevents`, `flippercontrol`, `flippersensors`, `flipperoperator`), so block opcodes match SPIKE (`flippermotor_motorTurnForDirection`). The GUI gets a B3 bar (Run/Stop, connection, control, port bar, PIN dialog, error banner) and loses stage, sprites, costumes, sounds tabs and the extension button. `hatd` serves the built editor, so editor and API share one origin.

**Tech Stack:** Node 24.21.0 (via nvm), npm workspaces, webpack (scratch-gui), React, scratch-vm (CommonJS, tests with `tap` 21), scratch-gui tests with Jest, Playwright for the end-to-end check, `hatd` from Plan 1.

**Spec:** `docs/superpowers/specs/2026-10-14-b3-design.md`

Plan 2b (Light, Sound on the Pi, project library + import/export, WeDo blocks, menu cleanup) is written after this plan is done.

## Global Constraints

- License AGPL-3.0; product name "B3"; never show "Scratch" or "LEGO"/"SPIKE" names or logos in the UI (Scratch TRADEMARK file).
- UI language: English only; no translation files for B3 strings.
- Node 24.21.0 via nvm: every shell command that runs node/npm starts with `export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 24.21.0 >/dev/null;` (written below as `<nvm>`).
- Extension ids are `/^[a-z0-9]+$/i`; final opcode = `<extensionId>_<opcode>`; B3 block opcodes reuse SPIKE names from spec Appendix A.
- Ports `A`–`D`; speeds are integers −100…100 %, positive = clockwise; default motor speed 75 %, default movement speed 50 %, default movement pair A+B, default 1 rotation = 17.5 cm.
- hatd WebSocket API version `"1"`; commands exactly as in Plan 1 (`motor.run_for {port, unit: degrees|seconds, value, speed}`, `motor.start`, `motor.stop`, `motor.go_to {port, position, direction: shortest|cw|ccw, speed 1..100}`, `pair.run_for {left, right, unit, left_value, right_value, left_speed, right_speed}`, `pair.start`, `pair.stop`, `stop_all`, `control.claim`, `ping`).
- Controller pings every 1 s.
- Errors on a block: show the message (naming the port), select the failing stack, stop the whole program. `interrupted` replies are silent (caused by Stop or a newer block).
- Low-voltage warning when `vin < 7.0`.
- Nothing is built on the Pi. Pi 4 work allowed without asking only inside `~/b3-dev` (deploy, tests, temporary hatd); everything else on the Pi needs consent.
- No downloads from Scratch servers at install time (micro:bit hex prepare step removed); no analytics.

## Review Focus

1. **hatd connection drops while a block waits** (Wi-Fi blip, hatd restart) — every pending block must end (not hang), the program stops, the bar shows "Disconnected", and it reconnects by itself (PIN again only if hatd restarted). → Task 3 tests.
2. **Program uses a port whose device is missing or of the wrong kind** (sensor block on a motor port, go-to-position on a Technic XL) — the user sees which port and what was expected, the program stops; hats on such ports simply never fire. → Tasks 4, 6, 7 tests.
3. **Editor opened by a second person** — Run without control must not move the robot and must say "Take control first"; Stop from a non-controller must not throw. → Tasks 3, 8 tests.
4. **Odd numeric inputs in blocks** (negative rotations, 0, text in a number slot, speed 250, steering ±100, position 720) — sane behaviour (negative = other direction, 0 = nothing, clamped speed, wrapped position), never a hatd `bad_args` error surfacing to a child. → Tasks 4, 5 tests.
5. **Green flag pressed repeatedly / Stop during a move** — per-port speeds and the timer reset on each Run, Stop sends exactly one `stop_all`, no stale replies resolve the wrong block. → Tasks 3, 6 tests.

```js
const EventEmitter = require('events');

const API_VERSION = '1';
const PORTS = ['A', 'B', 'C', 'D'];
const DEFAULT_SPEED = 75;
const RECONNECT_MS = 2000;
const PING_MS = 1000;

class B3CommandError extends Error {
    constructor (error) {
        super(error.message);
        this.code = error.code;
        this.port = error.port || null;
    }
}

/**
 * Connection to hatd on the Raspberry Pi plus the state B3 blocks share:
 * telemetry per port, per-port motor speed, movement settings and the timer.
 */
class B3Hub extends EventEmitter {
    constructor (runtime, options = {}) {
        super();
        this.runtime = runtime;
        /* global WebSocket, fetch, location */
        this._WebSocket = options.WebSocket || (typeof WebSocket === 'undefined' ? null : WebSocket);
        this._fetch = options.fetch || (typeof fetch === 'undefined' ? null : fetch.bind(globalThis));
        this._base = options.base || (typeof location === 'undefined' ? '' : location.origin);
        this._timers = options.timers || {setInterval, clearInterval, setTimeout, clearTimeout};
        this.state = 'idle';
        this.clientId = null;
        this.holder = null;
        this.ports = {A: null, B: null, C: null, D: null};
        this.vin = null;
        this._ws = null;
        this._nextId = 1;
        this._pending = new Map();
        this._ping = null;
        this.resetProgramState();
        runtime.on('PROJECT_START', () => this.resetProgramState());
        runtime.on('PROJECT_STOP_ALL', () => {
            if (this.isController) this.request('stop_all').catch(() => {});
        });
    }

    get isController () {
        return this.clientId !== null && this.holder === this.clientId;
    }

    resetProgramState () {
        this.speeds = {A: DEFAULT_SPEED, B: DEFAULT_SPEED, C: DEFAULT_SPEED, D: DEFAULT_SPEED};
        this.movement = {left: 'A', right: 'B', speed: 50, cmPerRotation: 17.5};
        this.timerStart = Date.now();
    }

    _setState (state) {
        if (this.state !== state) {
            this.state = state;
            this.emit('state', state);
        }
    }

    async start () {
        if (this.state === 'connecting' || this.state === 'connected') return;
        this._setState('connecting');
        let resp;
        try {
            resp = await this._fetch(`${this._base}/api/projects`, {credentials: 'same-origin'});
        } catch (e) {
            this._scheduleReconnect();
            return;
        }
        if (resp.status === 401) {
            this._setState('need-pin');
            return;
        }
        this._open();
    }

    async login (pin) {
        const resp = await this._fetch(`${this._base}/api/login`, {
            method: 'POST',
            credentials: 'same-origin',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({pin})
        });
        if (!resp.ok) {
            const body = await resp.json().catch(() => ({}));
            throw new Error(body.error ? body.error.message : 'Login failed');
        }
        this._setState('idle');
        await this.start();
    }

    _open () {
        const ws = new this._WebSocket(`${this._base.replace(/^http/, 'ws')}/api/ws`);
        this._ws = ws;
        ws.onmessage = event => this._onMessage(JSON.parse(event.data));
        ws.onclose = () => this._onClose(ws);
    }

    _onMessage (msg) {
        switch (msg.type) {
        case 'hello':
            this.clientId = msg.client_id;
            this.holder = msg.control.holder;
            this._send({type: 'hello', api_version: API_VERSION});
            this._setState('connected');
            this._updatePing();
            this.emit('control', this.holder);
            break;
        case 'reply': {
            const pending = this._pending.get(msg.id);
            if (!pending) return;
            this._pending.delete(msg.id);
            if (msg.ok) pending.resolve(msg.result);
            else pending.reject(new B3CommandError(msg.error));
            break;
        }
        case 'telemetry':
            this.ports = msg.ports;
            this.vin = msg.vin;
            this.emit('telemetry', msg);
            break;
        case 'device':
            this.emit('device', msg);
            break;
        case 'control':
            this.holder = msg.holder;
            this._updatePing();
            this.emit('control', msg.holder);
            break;
        }
    }

    _onClose (ws) {
        if (ws !== this._ws) return;
        this._ws = null;
        this.holder = null;
        this._updatePing();
        for (const pending of this._pending.values()) {
            pending.reject(new B3CommandError({code: 'disconnected', message: 'Connection to the robot lost'}));
        }
        this._pending.clear();
        this._setState('disconnected');
        this.runtime.stopAll();
        this._scheduleReconnect();
    }

    _scheduleReconnect () {
        this._setState('disconnected');
        this._timers.setTimeout(() => {
            if (this.state !== 'disconnected') return;
            this._setState('idle');
            this.start();
        }, RECONNECT_MS);
    }

    _send (msg) {
        if (this._ws && this._ws.readyState === 1) this._ws.send(JSON.stringify(msg));
    }

    request (cmd, args = {}) {
        if (!this._ws || this.state !== 'connected') {
            return Promise.reject(new B3CommandError({code: 'disconnected', message: 'Not connected to the robot'}));
        }
        const id = this._nextId++;
        return new Promise((resolve, reject) => {
            this._pending.set(id, {resolve, reject});
            this._send({id, cmd, args});
        });
    }

    async claimControl () {
        await this.request('control.claim');
    }

    _updatePing () {
        if (this.isController && this._ping === null) {
            this._ping = this._timers.setInterval(() => this.request('ping').catch(() => {}), PING_MS);
        } else if (!this.isController && this._ping !== null) {
            this._timers.clearInterval(this._ping);
            this._ping = null;
        }
    }

    device (port) {
        return (this.ports && this.ports[port]) || null;
    }
}

const getHub = runtime => {
    if (!runtime.b3hub) runtime.b3hub = new B3Hub(runtime);
    return runtime.b3hub;
};

module.exports = {API_VERSION, PORTS, B3CommandError, B3Hub, getHub};
```

```js
/**
 * Shared helpers for B3 blocks: sending commands to hatd and reporting problems
 * the way the spec asks (message naming the port, failing stack, program stops).
 */

const fail = (hub, util, message, port = null) => {
    hub.emit('blockError', {message, port, blockId: util && util.thread ? util.thread.topBlock : null});
    hub.runtime.stopAll();
};

const send = (hub, util, cmd, args) => hub.request(cmd, args).catch(error => {
    if (error.code === 'interrupted') return; // Stop pressed or a newer block took over the port
    fail(hub, util, error.message, error.port || null);
});

const deviceOfKind = (hub, port, kinds) => {
    const device = hub.device(port);
    return device && kinds.includes(device.kind) ? device : null;
};

const requireDevice = (hub, util, port, kinds, expected) => {
    const device = deviceOfKind(hub, port, kinds);
    if (device) return device;
    const found = hub.device(port);
    fail(hub, util, `Port ${port}: expected ${expected}, found ${found ? found.name : 'nothing'}`, port);
    return null;
};

module.exports = {fail, send, deviceOfKind, requireDevice};
```

```js
            value = -value;
            speed = -speed;

        const unit = args.UNIT === 'seconds' ? 'seconds' : 'degrees';
        if (args.UNIT === 'rotations') value *= 360;
        return send(this.hub, util, 'motor.run_for', {port: args.PORT, unit, value, speed});

            port: args.PORT,
            position: wrap360(Cast.toNumber(args.POSITION)),
            direction: GO_TO_DIRECTIONS[args.DIRECTION] || 'shortest',
            speed
        });
    }

    motorStartDirection (args, util) {
        return send(this.hub, util, 'motor.start',
            {port: args.PORT, speed: this._signedSpeed(args.PORT, args.DIRECTION)});
    }

    motorStop (args, util) {
        return send(this.hub, util, 'motor.stop', {port: args.PORT});
    }

    motorSetSpeed (args) {
        this.hub.speeds[args.PORT] = toSpeed(args.SPEED);
    }

        const device = requireDevice(this.hub, util, args.PORT, ENCODER_KINDS, 'motor with encoder');

        const device = requireDevice(this.hub, util, args.PORT, MOTOR_KINDS, 'motor');
        if (!device) return 0;
        return device.kind === 'motor_passive' ? device.power : device.speed;
    }
```

```js
const {clamp} = require('./menus');

const CM_PER_INCH = 2.54;

/**
 * Wheel speeds for a driving base. The left motor is mounted mirrored, so driving
 * forward turns it counterclockwise (negative). Steering -100..100: the inner wheel
 * slows down by 1 - |steering|/50 (0 at 50 = pivot, reversed at 100 = spin).
 */
const wheelSpeeds = (speed, steering) => {
    const s = clamp(steering, -100, 100);
    const factor = 1 - (Math.abs(s) / 50);
    let left = speed;
    let right = speed;
    if (s > 0) right = speed * factor;
    if (s < 0) left = speed * factor;
    return {left: -Math.round(left) || 0, right: Math.round(right) || 0};
};

const toDegrees = (value, unit, cmPerRotation) => {
    switch (unit) {
    case 'cm': return value / cmPerRotation * 360;
    case 'in': return value * CM_PER_INCH / cmPerRotation * 360;
    case 'rotations': return value * 360;
    case 'degrees': return value;
    default: return null;
    }
};

const pairRunArgs = (movement, steering, value, unit) => {
    if (!Number.isFinite(value) || value === 0 || movement.speed === 0) return null;
    const speed = value < 0 ? -movement.speed : movement.speed;
    const amount = Math.abs(value);
    const {left, right} = wheelSpeeds(speed, steering);
    const base = {left: movement.left, right: movement.right, left_speed: left, right_speed: right};
    if (unit === 'seconds') {
        return {...base, unit: 'seconds', left_value: amount, right_value: amount};
    }
    const degrees = toDegrees(amount, unit, movement.cmPerRotation);
    const fastest = Math.max(Math.abs(left), Math.abs(right));
    if (degrees === null || fastest === 0) return null;
    return {
        left: movement.left,
        right: movement.right,
        unit: 'degrees',
        left_value: degrees * Math.abs(left) / fastest,
        right_value: degrees * Math.abs(right) / fastest,
        left_speed: left,
        right_speed: right
    };
};

module.exports = {wheelSpeeds, toDegrees, pairRunArgs};
```

```js
const wrap = n => ((Math.round(n) % 360) + 360) % 360;

const valueOf = device => {

    case 'motor_rel': return `${wrap(device.position)}°`;

    default: return '';
```

`src/containers/b3-bar.jsx`:
```jsx
import PropTypes from 'prop-types';
import React from 'react';
import B3BarComponent from '../components/b3-bar/b3-bar.jsx';

const snapshot = hub => ({
    state: hub.state,
    isController: hub.isController,
    hasController: hub.holder !== null,
    ports: hub.ports,
    vin: hub.vin
});

class B3Bar extends React.Component {
    constructor (props) {
        super(props);
        this.hub = props.vm.b3hub;
        this.state = {...snapshot(this.hub), error: null, pinError: null};
        this.refresh = () => this.setState(snapshot(this.hub));
        this.onBlockError = e => {
            this.setState({error: e.message});
            const workspace = this.props.vm.runtime && this.props.vm.runtime.b3workspace;
            if (workspace && e.blockId) {
                const block = workspace.getBlockById(e.blockId);
                if (block) {
                    block.select();
                    workspace.centerOnBlock(e.blockId);
                }
            }
        };
        this.handleRun = () => this.props.vm.greenFlag();
        this.handleStop = () => this.props.vm.stopAll();
        this.handleTakeControl = () => this.hub.claimControl().catch(e => this.setState({error: e.message}));
        this.handleLogin = pin => this.hub.login(pin)
            .then(() => this.setState({pinError: null}))
            .catch(e => this.setState({pinError: e.message}));
        this.handleDismissError = () => this.setState({error: null});
    }

    componentDidMount () {
        for (const name of ['state', 'telemetry', 'control']) this.hub.on(name, this.refresh);
        this.hub.on('blockError', this.onBlockError);
        this.hub.start();
    }

    componentWillUnmount () {
        for (const name of ['state', 'telemetry', 'control']) this.hub.removeListener(name, this.refresh);
        this.hub.removeListener('blockError', this.onBlockError);
    }

    render () {
        return (
            <B3BarComponent
                {...this.state}
                onDismissError={this.handleDismissError}
                onLogin={this.handleLogin}
                onRun={this.handleRun}
                onStop={this.handleStop}
                onTakeControl={this.handleTakeControl}
            />
        );
    }
}

B3Bar.propTypes = {
    vm: PropTypes.shape({
        b3hub: PropTypes.object, // eslint-disable-line react/forbid-prop-types
        greenFlag: PropTypes.func,
        stopAll: PropTypes.func,
        runtime: PropTypes.object // eslint-disable-line react/forbid-prop-types
    }).isRequired
};

export default B3Bar;
```
