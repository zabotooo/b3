# B3 Install and Release (Plan 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person with a Raspberry Pi and a Build HAT installs B3 with one line, gets a running service with a PIN and a URL, and later updates or removes it with the same script.

**Architecture:**
- GitHub Actions (repository `zabotooo/b3`) tests everything, builds a production editor and packs it with hatd into `b3.tar.gz`. A `v*` tag publishes that archive as a GitHub release.
- `install/install.sh` runs on the Pi as root. It enables the UART, installs apt packages, unpacks the release to `/opt/b3`, keeps data in `/var/lib/b3` and runs hatd as the systemd service `b3` under a system user `b3`.
- Three small runtime changes go with it:
  - hatd closes WebSockets on shutdown;
  - hatd serves editor files with `Cache-Control: no-cache`;
  - the editor shows an API-version mismatch instead of reconnecting forever.

**Tech Stack:**
- Bash for `install.sh`, `make-release.sh` and `ci/e2e.sh`;
- systemd;
- GitHub Actions;
- Python 3.11 with aiohttp 3.8.4, as on bookworm, and pytest for hatd and the installer tests;
- webpack 5 for the production editor;
- tap and Jest for editor unit tests, Playwright for e2e.

**Spec:** `docs/superpowers/specs/2026-10-14-b3-design.md`, sections 3.3, 4.2 (handshake), 6 (`hatd` crash), 7 (Installation and releases) and 10 (Repository layout).

## Global Constraints

- "Nothing is built on the Pi (webpack needs GBs of RAM). GitHub Actions builds the editor on each release and packs it with `hatd` into one release archive."
- `install.sh` on Raspberry Pi OS bookworm does, in this order:
  - enables UART and disables the serial console (`raspi-config nonint`);
  - installs `python3-build-hat` and `python3-aiohttp` via apt (no pip);
  - puts the release in `/opt/b3` and the data (projects, sound cache, config) in `/var/lib/b3`;
  - installs and enables a systemd service;
  - generates a PIN and prints it with the URL (`http://<hostname>.local`);
  - offers a reboot if the UART settings changed.
- "The same script updates and uninstalls."
- "Configuration file: PIN, audio output device, HTTP port."
- "`hatd` crash → systemd restarts it."
- "Handshake: `hello {api_version}` both ways; mismatched major version → error shown in editor."
- UI language: English only. The names "LEGO" and "SPIKE" are not used in the product name.
- License AGPL-3.0.
- Target runtime: Python 3.11.2, aiohttp 3.8.4, buildhat 0.6.0, pytest 7.2.1, pytest-asyncio 0.20.3. These are the bookworm packages measured on the Pi. CI pins the same versions.
- User decisions (2026-10-17):
  - GitHub repository `zabotooo/b3`, public;
  - generated PIN has 4 digits;
  - the real installation is tried on the Pi 4 `pipina2` (`<user>@<pi-ip>`).
- Project rules from `CLAUDE.md` bind the executor. On the Pi, only work inside `~/b3-dev` (deploy, tests, temporary hatd) needs no question. Each of the following needs the user's explicit consent, given for that one action:
  - running `install.sh` on the Pi;
  - any `sudo`, systemd or apt command there;
  - a reboot;
  - moving motors outside tests;
  - `git push`, creating tags and anything sent to GitHub.

## Review Focus

1. **Update over an existing install.** It must keep `config.toml` (PIN, audio device), the projects and the sound cache. Pinned by `test_update_keeps_config_and_projects` (Task 6).
2. **Failed or partial download.** The old `/opt/b3` and the running service stay untouched, and the script exits non-zero with the URL it tried. Pinned by `test_failed_download_keeps_old_install` (Task 6).
3. **Browser holding an old editor after an update.** Index and bundles are revalidated (`test_editor_files_are_revalidated`, Task 2). A tab left open shows "reload" instead of a reconnect loop (`hello with another major API version stops and does not reconnect`, Task 3).
4. **Pi where UART is already set up (the Pi 4 today).** No raspi-config change and no reboot hint. Pinned by `test_fresh_install` (Task 6).
5. **Service user permissions.** The `b3` user needs:
   - `/dev/serial0` (dialout);
   - `/dev/gpiochip*` (gpio, used by buildhat to reset the HAT);
   - ALSA (audio) while the desktop user's PipeWire is running;
   - a writable working directory (lgpio creates its notify files in the cwd).

   This cannot be unit-tested. It is the checklist in Task 8, step 4.

### Task 1: hatd closes WebSockets on shutdown

When a browser had the editor open, hatd did not stop on SIGTERM. aiohttp's shutdown waits up to 60 s for the open WebSocket handlers. With systemd this means every `systemctl restart b3` and every update hangs.

**Files:**
- Modify: `hatd/b3hatd/clients.py` (new `close_all`)
- Modify: `hatd/b3hatd/app.py` (`on_shutdown` hook)
- Modify: `hatd/b3hatd/__main__.py` (`shutdown_timeout`)
- Test: `hatd/tests/test_shutdown.py` (new)

**Interfaces:**
- Produces: `Clients.close_all() -> None` (async). hatd exits within 3 s of SIGTERM even with a client connected; Task 8 checks this on the Pi.

- [ ] **Step 1: Write the failing test** `hatd/tests/test_shutdown.py`:

```python
"""hatd as a real process: SIGTERM with an editor connected must not hang."""

import asyncio
import signal
import socket
import sys
import time
from pathlib import Path

import aiohttp

HATD_DIR = Path(__file__).resolve().parents[1]


def _free_port() -> int:
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]


async def _login(session: aiohttp.ClientSession, base: str) -> None:
    for _ in range(100):
        try:
            resp = await session.post(f"{base}/api/login", json={"pin": "1234"})
            assert resp.status == 200
            return
        except aiohttp.ClientConnectionError:
            await asyncio.sleep(0.1)
    raise AssertionError("hatd did not start")


async def test_sigterm_with_open_websocket_exits_quickly(tmp_path):
    port = _free_port()
    cfg = tmp_path / "config.toml"
    cfg.write_text(
        'pin = "1234"\n'
        f'data_dir = "{tmp_path}"\n'
        f'static_dir = "{tmp_path / "editor"}"\n'
        'http_host = "127.0.0.1"\n'
        f"http_port = {port}\n"
    )
    proc = await asyncio.create_subprocess_exec(
        sys.executable, "-m", "b3hatd", "--config", str(cfg), "--sim", cwd=HATD_DIR,
        stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.DEVNULL)
    try:
        base = f"http://127.0.0.1:{port}"
        async with aiohttp.ClientSession(cookie_jar=aiohttp.CookieJar(unsafe=True)) as session:
            await _login(session, base)
            ws = await session.ws_connect(f"{base}/api/ws")
            await ws.receive_json(timeout=2)  # hello
            started = time.monotonic()
            proc.send_signal(signal.SIGTERM)
            while True:  # telemetry keeps coming until hatd closes the socket
                msg = await ws.receive(timeout=5)
                if msg.type != aiohttp.WSMsgType.TEXT:
                    break
            assert await asyncio.wait_for(proc.wait(), 5) == 0
            assert time.monotonic() - started < 3
    finally:
        if proc.returncode is None:
            proc.kill()
            await proc.wait()
```

- [ ] **Step 3: Implement.** In `hatd/b3hatd/clients.py`, change the import to `from aiohttp import WSCloseCode, web` and add this method to `Clients`:

```python
    async def close_all(self) -> None:
        """Close every connection (hatd is stopping); editors reconnect by themselves."""
        sockets = list(self._ws.values())
        self._ws.clear()
        await asyncio.gather(*(ws.close(code=WSCloseCode.GOING_AWAY, message=b"hatd stopping")
                               for ws in sockets), return_exceptions=True)
```

In `hatd/b3hatd/app.py`, add the following next to `_on_cleanup`:

```python
async def _on_shutdown(app: web.Application) -> None:
    # aiohttp waits for open WebSocket handlers before cleanup; end them first
    await app[CLIENTS].close_all()
```

Register it in `create_app` before `app.on_cleanup.append(_on_cleanup)`:

```bash
#!/bin/bash
# B3 (BuildBrickBlocks) installer for Raspberry Pi OS bookworm with a Build HAT.
#
#   Install or update:  curl -sSL https://raw.githubusercontent.com/zabotooo/b3/main/install/install.sh | sudo bash
#   Uninstall:          curl -sSL …/install.sh | sudo bash -s -- uninstall [--purge]
#
#   B3_VERSION=0.1.0   install that release instead of the latest
#   B3_ARCHIVE=file    install a local release archive (b3.tar.gz) instead of downloading
#   B3_ROOT=dir        prefix for every system path (tests only)
set -euo pipefail

B3_REPO="zabotooo/b3"
ROOT="${B3_ROOT:-}"
OPT="$ROOT/opt/b3"
DATA="$ROOT/var/lib/b3"
UNIT="$ROOT/etc/systemd/system/b3.service"
SERVICE_USER=b3
REBOOT=0

say() { echo "b3: $*"; }
die() { echo "b3: error: $*" >&2; exit 1; }

need_root() {
    [ -n "$ROOT" ] || [ "$(id -u)" = 0 ] || die "run as root: curl -sSL … | sudo bash"
}

archive_url() {
    if [ -n "${B3_VERSION:-}" ]; then
        echo "https://github.com/$B3_REPO/releases/download/v$B3_VERSION/b3.tar.gz"
    else
        echo "https://github.com/$B3_REPO/releases/latest/download/b3.tar.gz"
    fi
}

setup_uart() {
    # raspi-config: get_serial_hw prints 0 when the UART is on, get_serial_cons 0 when the console is on
    if [ "$(raspi-config nonint get_serial_hw)" != 0 ]; then
        say "enabling the serial port for the Build HAT"
        raspi-config nonint do_serial_hw 0
        REBOOT=1
    fi
    if [ "$(raspi-config nonint get_serial_cons)" = 0 ]; then
        say "disabling the serial console (the Build HAT needs the port)"
        raspi-config nonint do_serial_cons 1
        REBOOT=1
    fi
}

install_packages() {
    say "installing packages"
    apt-get update -q
    DEBIAN_FRONTEND=noninteractive apt-get install -y -q python3-build-hat python3-aiohttp alsa-utils
}

ensure_user() {
    if ! id "$SERVICE_USER" >/dev/null 2>&1; then
        # dialout: /dev/serial0, gpio: Build HAT reset pin, audio: sound output
        useradd --system --user-group --home-dir /var/lib/b3 --no-create-home \
            --shell /usr/sbin/nologin --groups dialout,gpio,audio "$SERVICE_USER"
    fi
}

fetch_release() {  # $1: empty work dir; leaves the release in $1/b3
    local archive="${B3_ARCHIVE:-}"
    if [ -z "$archive" ]; then
        archive="$1/b3.tar.gz"
        say "downloading $(archive_url)"
        curl -fsSL "$(archive_url)" -o "$archive" || die "download failed: $(archive_url)"
    fi
    tar -xzf "$archive" -C "$1" || die "not a B3 release archive: $archive"
    [ -f "$1/b3/VERSION" ] || die "not a B3 release archive (no b3/VERSION): $archive"
}

install_files() {  # $1: unpacked release
    mkdir -p "$(dirname "$OPT")" "$(dirname "$UNIT")"
    rm -rf "$OPT.new" "$OPT.old"
    cp -a "$1" "$OPT.new"
    systemctl stop b3 2>/dev/null || true
    if [ -e "$OPT" ]; then
        mv "$OPT" "$OPT.old"
    fi
    mv "$OPT.new" "$OPT"
    rm -rf "$OPT.old"
    cp "$OPT/install/b3.service" "$UNIT"
}

write_config() {
    mkdir -p "$DATA"
    if [ ! -f "$DATA/config.toml" ]; then
        local pin audio=""
        pin=$(printf '%04d' $(( $(od -An -N2 -tu2 /dev/urandom) % 10000 )))
        if aplay -l 2>/dev/null | grep -q '^card [0-9]*: Headphones'; then
            audio='audio_device = "plughw:CARD=Headphones,DEV=0"'
        fi
        cat > "$DATA/config.toml" <<EOF
# B3 settings; restart after a change: sudo systemctl restart b3
pin = "$pin"
data_dir = "/var/lib/b3"
static_dir = "/opt/b3/editor"
http_port = 80
$audio
EOF
        chmod 600 "$DATA/config.toml"
    fi
    chown -R "$SERVICE_USER:$SERVICE_USER" "$DATA"
}

start_service() {
    systemctl daemon-reload
    systemctl enable b3
    systemctl restart b3
}

offer_reboot() {
    say "The serial port settings changed; the Build HAT works after a reboot."
    if [ -z "$ROOT" ] && (exec </dev/tty) 2>/dev/null; then
        local answer=""
        read -r -p "b3: Reboot now? [y/N] " answer </dev/tty || true
        if [ "$answer" = y ] || [ "$answer" = Y ]; then
            reboot
        fi
    fi
    say "Reboot later with: sudo reboot"
}

do_install() {
    need_root
    setup_uart
    install_packages
    ensure_user
    WORK=$(mktemp -d)  # global: the EXIT trap runs after this function returns
    trap 'rm -rf "$WORK"' EXIT
    fetch_release "$WORK"
    install_files "$WORK/b3"
    write_config
    start_service
    local pin
    pin=$(sed -n 's/^pin = "\(.*\)"$/\1/p' "$DATA/config.toml")
    say "B3 $(cat "$OPT/VERSION") is running."
    say "Open http://$(hostname).local in a browser. PIN: $pin"
    if [ "$REBOOT" = 1 ]; then
        offer_reboot
    fi
}

do_uninstall() {
    need_root
    systemctl disable --now b3 2>/dev/null || true
    rm -f "$UNIT"
    systemctl daemon-reload
    rm -rf "$OPT"
    if [ "${1:-}" = --purge ]; then
        rm -rf "$DATA"
        userdel "$SERVICE_USER" 2>/dev/null || true
        say "B3 removed, with its projects and settings."
    else
        say "B3 removed. Projects and settings are kept in /var/lib/b3 (uninstall --purge removes them)."
    fi
}

case "${1:-install}" in
    install) do_install ;;
    uninstall) shift; do_uninstall "$@" ;;
    *) echo "usage: install.sh [install | uninstall [--purge]]" >&2; exit 2 ;;
esac
```

## Not in this plan

- **Smaller release.** `static/assets` (tutorial decks and library images) and `chunks/mediapipe` are copied whole, although B3 uses neither. Pruning them needs care, because the GUI imports some of them at startup.
- **PIN hardening.** With 4 digits and a 1 s delay per wrong attempt, parallel guesses can find the PIN in minutes. Serializing failed logins in `auth.py` (one at a time) would raise that to about 3 hours. This is a small change to propose to the user separately.
- **Phase 2** (headless VM on the Pi), `.deb`/apt repository, SD-card image, Wi-Fi hotspot mode.
- Deferred minors from plan 2b (see the project memory).
